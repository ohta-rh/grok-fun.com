**[should] 「コンピュータが 1 台な話は」（本文「どこで使えて、いくら払うか」と「関連する TIPS」の 2 か所）**
「1 台な話」は日本語として崩れている。名詞に「な」は付かない。音読すると引っかかる。
差し替え: 「コンピュータが 1 台ある話は、<a href="/tips/grok-bot-cloud-computer/">クラウドのコンピュータ</a>です。」（2 か所とも）

**[should] 「続きの投稿が、[モデルのページ] へ繋いでいます。」**
投稿がページへ「繋ぐ」は英語の links to の載せ替え。日本語ではリンクが「ある」。
差し替え: 「続きの投稿に、[モデルのページ](https://docs.x.ai/developers/models/grok-imagine-video-1.5-lite) へのリンクがあります。」

**[should] 「出力の行は、秒 $0.02 です。解像度の表では、480p が同じ金額です。」**
読者は「出力の行」が何の行か分からない。モデルページの料金表の話だと一度も言っていない。数字と事実はそのまま。
差し替え: 「そのページの料金表には、出力は秒 $0.02、とあります。解像度の表の 480p と同じ金額です。」

**[should] 「2026-09-21 に出た自社のモデルは、Grok 4.7 です。」**
「自社」が誰の会社か、この段落では一度も出ていない。前の段落は Musk と Imagine と Bot の話で、xAI の名前が無い。
差し替え: 「xAI が自分で作ったモデルは、2026-09-21 に出た Grok 4.7 です。」

**[nit] 見出し「軽い動画の単価は、解像度で分かれる」と、図の中の「解像度で変わる」**
同じページで見出しと図の言い方が違う。どちらも普通の文だけど、図と alt と caption は「変わる」で揃っているので、見出しだけ浮く。
差し替え: 「## 軽い動画の単価は、解像度で変わる」

**[nit] 「<strong>本体は Claude Opus 5.5 です。</strong>いちばん上の図は、その判断です。」**
「図は判断です」は、このサイトの内輪の言い方。読者には「図＝判断」が繋がらない。
