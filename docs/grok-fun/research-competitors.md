# 競合調査: Grok シリーズの日本語情報サイト

- 日付: 2026-09-08
- 目的: grok-fun.com が埋める隙間を特定する
- 方法: 検索結果の観測（2026-09 上旬）。数値は観測時点のもの。順位は変動する

## 結論

**Grok シリーズ全体（chat / Bot / Build / Imagine / Voice / Automations / API）を一箇所で追う日本語ハブは存在しない。** 既存プレイヤーは「Bot のプロンプト集」か「単発の使い方記事」のどちらかで、シリーズ横断の製品地図と料金・制限の変更履歴を持つサイトが無い。ここが隙間。

## プレイヤー分類

| 種別 | 代表 | 扱う範囲 | 更新 | 弱点 |
|---|---|---|---|---|
| Bot 特化 | grokguide.jp | Bot 用プロンプト集（観測時 684 本）。Bot 以外はほぼ無し | プロンプト追加は続いている | chat / Build / Imagine / API を扱わない。料金・制限の追随なし。製品地図なし |
| 汎用 AI メディア | 大手 AI 系ブログ、ビジネス系メディア | 「grok 使い方」「grok とは」「grok 料金」の単発記事 | 公開後ほぼ更新されない。バージョン表記が 3 や 4 で止まっているものが多い | 一次情報リンクが薄い。変更履歴を持たない。シリーズ横断の視点が無い |

## 観測した事実

### grokguide.jp

- Bot 向けプロンプトを 684 本掲載（観測時のカウント）。
- 製品としては Bot（旧: カスタム指示）のみを対象にしている。chat 本体の料金プラン、Imagine の生成制限、API の料金、Build の使い方は扱っていない。
- 「grok bot プロンプト」系の長尾クエリでは強い。ここを正面から取りに行く必要は無い。

### 汎用 AI メディア

- 「grok 使い方」「grok とは」「grok 料金」の上位は grok.com、X、大手メディアの一本記事で埋まっている。
- 記事内のモデル名・料金が古いままのものが多い（Grok 3 前提、旧料金）。読者は「今どうなの」を知りたいので、ここに正直な `last_verified` を付けたページで勝てる余地がある。
- 全文翻訳っぽい記事も散見される。fable-review の指摘 2 の通り、そこには乗らない。

### 公式

- x.ai/news は英語。日本語の要約が無い。
- x.ai/pricing は USD のみ。App Store / Google Play の JPY 価格と一致しない。この「差」を説明するページが日本語には無い。
- docs.x.ai は API 開発者向け。非エンジニアが「Automations って何」を調べる場所が無い。

## 隙間（grok-fun.com が取る位置）

1. **シリーズ横断の製品地図。** 7 製品を 1 ページに並べ、「無料でどこまで」「どのプランで解放」「日本で使えるか」を表にする。競合ゼロ。
2. **料金・制限の変更履歴。** 日付付きの差分形式。USD 表示 + ストア課金の注記。競合ゼロ。
3. **公式ニュースの日本語要約 + 原文リンク + 日付。** 全文翻訳はしない。速さ（72 時間 SLA）で汎用メディアに勝つ。
4. **製品名 × 具体属性の長尾（Tier A）。** `grok imagine 動画 制限` `grok api 料金 円` `grok build 使い方` のような、公式にも汎用メディアにも無い組み合わせ。

## 取らない位置

- Bot プロンプト集。grokguide.jp が既に 684 本。後追いで勝てず、勝っても価値が薄い。Bot ハブは「設定方法 + 日本語での注意点 + grokguide.jp への外部リンク」で十分。
- 「grok とは」「grok 使い方」の頭語。Tier C、観測のみ（research-seo-content.md 参照）。
- 全文翻訳。法務と SEO の両方で負ける。
