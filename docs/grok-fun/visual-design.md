# ビジュアルデザイン: grok-fun.com

- 日付: 2026-09-08
- 設計者: Fable 5.1
- 位置づけ: **Grok JP ／ ファンコミュニティ（非公式）**（サイト名は 2026-09-08 オーナー決定。ヘッダ文字列以外は原案のまま）。日本語の **非公式 Grok シリーズ「参照デスク」**。SaaS のランディングでも grok.com の模倣でもない。図書館のレファレンスカウンターと、受験参考書の紙面を掛け合わせる

## コンセプト: 「参考書 × 索引カード」

読者がここに来る理由は「今、Grok の何がいくらで、どこまで使えるか」を 30 秒で知ること。感動させる必要は無い。**数字と日付が一番早く目に入る紙面**を作る。

- 紙は白、文字は墨。装飾は罫線と蛍光マーカーだけ。
- 全ページが 1 枚の索引カード。上端に「製品タグ / 最終確認日 / 追随状況」のカード見出し。
- 重要な数字と日付は蛍光マーカーで塗る。参考書で赤シートを当てる箇所。
- 「非公式」は朱肉の判子として押す。隠さない。飾らない。
- 写真もイラストもヒーロー画像も無し。OGP だけ判子とサイト名の組版で作る。

## カラートークン（6 個）

| トークン | Hex | 役割 | 使う場所 |
|---|---|---|---|
| `--ink` | `#1C2230` | 本文、見出し | 全テキスト。純黒は使わない |
| `--paper` | `#F3F4F0` | 背景 | ページ全体。クリームではなく、わずかに緑がかった寒色の紙 |
| `--rule` | `#C9CCC4` | 罫線 | 見出し下線、テーブル罫、カード枠、区切り |
| `--indigo` | `#2B4C9B` | 藍。リンク、製品タグ、アクティブな導線 | リンク下線、ハブのタグ、ナビの現在地 |
| `--marker` | `#FFD64A` | 蛍光マーカー | 数字・日付・料金のハイライト、押したリアクションチップの背景、`last_verified` の日付 |
| `--stamp` | `#C8322B` | 朱肉 | 「非公式」判子、`last_verified` 60 日超の警告、エラー文。**1 画面に 2 か所まで** |

補助（トークン化しない。CSS 内で `color-mix()` で派生）:

- `--ink` の 60% を注釈色（`color-mix(in oklab, var(--ink) 60%, var(--paper))`）
- `--marker` の 35% を淡いハイライト帯（テーブルの強調行）

コントラスト: `--ink` on `--paper` 14.6:1。`--indigo` on `--paper` 7.1:1。`--ink` on `--marker` 11.9:1。`--paper` on `--stamp` 5.4:1。すべて AA 通過、本文は AAA。

```css
:root {
  --ink: #1C2230;
  --paper: #F3F4F0;
  --rule: #C9CCC4;
  --indigo: #2B4C9B;
  --marker: #FFD64A;
  --stamp: #C8322B;
  --ink-60: color-mix(in oklab, var(--ink) 60%, var(--paper));
  --marker-35: color-mix(in oklab, var(--marker) 35%, var(--paper));
}
```

## タイポグラフィ

有料 CDN も Google Fonts の外部 fetch も使わない。Fontsource で self-host。

| 役割 | フォント | パッケージ | ウェイト |
|---|---|---|---|
| 本文・見出し・UI | **BIZ UDPGothic** | `@fontsource/biz-udpgothic` | 400 / 700 |
| 数字・日付・料金・slug・コード | **IBM Plex Mono** | `@fontsource/ibm-plex-mono` | 400 / 500 |

フォールバック:

```css
--font-sans: 'BIZ UDPGothic', 'Hiragino Sans', 'Yu Gothic', 'Noto Sans JP', system-ui, sans-serif;
--font-mono: 'IBM Plex Mono', 'SFMono-Regular', Menlo, monospace;
```

理由:

- BIZ UDPGothic は教科書・行政文書・時刻表で使われる UD フォント。「参照デスク」の声に合う。字面が大きく、数字が読みやすい。Noto Sans JP より個性がある。
- IBM Plex Mono は等幅で数字の桁が揃う。料金表・制限値の表を「読む」ではなく「見比べる」ために必須。
- Fontsource の日本語フォントは Google Fonts と同じ unicode-range 分割で配信されるので、実際に読み込まれるのは使用グリフの範囲だけ。ファイル数は 100 前後で、Static Assets の 20,000 上限には影響しない。
- `font-display: swap`。初回描画はフォールバックの Hiragino / Yu Gothic で出る。

サイズ（`clamp` で流動）:

| 要素 | サイズ | 行間 |
|---|---|---|
| 本文 | `clamp(16px, 1rem + 0.2vw, 18px)` | 1.8 |
| 見出し h1 | `clamp(26px, 1.4rem + 1vw, 34px)` 700 | 1.35 |
| h2 | `clamp(20px, 1.1rem + 0.5vw, 24px)` 700、下に `--rule` 1px | 1.4 |
| h3 | 本文と同サイズ、700、先頭に `--indigo` の縦棒 3px | 1.5 |
| 注釈・日付 | 14px mono `--ink-60` | 1.6 |
| テーブル | 15px、数字は mono | 1.5 |

見出しに文字間隔の調整はしない。日本語の詰めは崩れる。

## レイアウト原則

1. **ヒーロー無し。** トップは製品地図の表から始まる。
2. **1 カラム。** 本文 max-width 40rem（17px で 1 行 37 字前後）。テーブルは min-width 34rem、狭い画面では .table-scroll で横スクロール。サイドバー無し。目次はページ内 `<details>`。
3. **カード見出し。** 全ページの h1 の上に 1 行: `[製品タグ] · 最終確認 2026-09-08 · 追随: tracking`。mono。これが索引カードの上端。
4. **罫線は水平のみ。** 縦線と影は使わない。角丸は 2px。
5. **マーカーは 1 段落に 1 か所。** 塗りすぎると参考書ではなく落書きになる。
6. **数字は必ず mono。** 本文中の「$30」「72 時間」も `<span class="num">`。
7. **判子は右上に固定。** 非公式バナーは 1 行テキスト + 判子。スクロールで追わない。
8. **リアクションとコメントは本文の下。** 本文の読みを邪魔しない。本文 → 原文リンク → 罫線 → リアクション → コメント。
9. **JS 無しで完成している。** ウィジェットは JS が来たら置き換わる。来なければ「いま反応を受け付けていません」のまま。
10. **モバイルはデスクトップの縮小ではなく、同じ 1 カラムの余白違い。** ブレークポイントは 1 つ（`48rem`）。

余白: ページ左右 `clamp(16px, 4vw, 48px)`。セクション間 `2.5rem`。

## コンポーネント

### 非公式判子 `UnofficialBanner`

- 上部バナー: 1 行、`--paper` 背景、`--rule` 下線、14px。文言「このサイトは Grok の非公式ファンコミュニティです。xAI とは関係ありません。」
- 判子: 右上、`--stamp` 2px 枠 + `--stamp` 文字「非公式」、角丸 2px、`transform: rotate(-4deg)`、背景透過。サイズ 56×28px。印刷の朱肉のように、少し傾ける。
- 判子は装飾ではなく法務表示。`aria-label="非公式サイト"`。

### カード見出し `CardHeader`

- mono 14px `--ink-60`。`[product] · 最終確認 YYYY-MM-DD · 追随: full|tracking|index`。
- `product` は `--indigo` の文字色 + `--indigo` 1px 枠の小タグ。
- 日付は `--marker-35` の帯を敷く（薄いマーカー）。

### 古さ警告 `StaleBanner`

- 60 日超で表示。`--stamp` 1px 枠、`--paper` 背景、文字 `--ink`。先頭に `--stamp` の縦棒 3px。
- 文言: 「この情報は YYYY-MM-DD に最後に確認したものです。古い可能性があります。」
- 1 ページ 1 個。判子と合わせて `--stamp` は画面に 2 か所まで、の上限に収まる。

### リアクションチップ `ReactionBar`

```
( 👍 12 )   通常:   --paper 背景、--rule 1px 枠、角丸 999px、高さ 36px、左右 12px
                    emoji 18px、count は mono 14px --ink
( 👍 13 )   押した: --marker 背景、--ink 1px 枠。localStorage で記憶。再度押しても増えない
( 👍 )      劣化:   count 非表示、--ink-60 文字、--rule 枠、cursor: default、
                    バーの右に「いま反応を受け付けていません」14px --ink-60
```

- 5 個固定: `👍 🔥 🤔 📌 😂`。順序も固定。API の許可リストと一致。
- ホバーは `--rule` 背景。フォーカスは `--indigo` 2px アウトライン。
- 押した瞬間に楽観的に +1 して `--marker` に変える。API が失敗したら戻し、劣化表示へ。
- `<button type="button" aria-pressed="true|false">`。JS 無しでは `disabled`。
- モバイルでは折り返し（`flex-wrap`）。1 行に 3〜4 個。

### コメントフォーム `CommentForm`

- 見出し「コメント n 件」。n は API から。劣化時は「コメント」のみ。
- フィールド 2 つだけ:
  - ニックネーム: `<input maxlength="24" placeholder="匿名">`。ラベル「ニックネーム（任意・24 文字まで）」。
  - 本文: `<textarea maxlength="500" rows="3">`。ラベル「本文（500 文字まで）」。右上に mono のカウンタ `0 / 500`。480 を超えたら `--stamp` 色。
- Turnstile ウィジェットは送信ボタンの左。Managed モード、テーマ `light`。
- 送信ボタン「書き込む」: `--ink` 背景、`--paper` 文字、角丸 2px、高さ 40px。ホバーで `--indigo`。送信中は「送信中…」で `disabled`。
- 成功: フォームをクリアし、一覧の先頭に新しいコメントを `--marker-35` の帯で 2 秒表示して消す。
- 失敗: フォーム直下に `--stamp` 文字 14px で 1 行。「投稿できませんでした。時間をおいて再度お試しください。」403 なら「確認に失敗しました。ページを再読み込みしてください。」
- フォームは枠 `--rule` 1px、内側余白 16px。影なし。
- 注記（フォーム下、`--ink-60` 12px）: 「アカウント不要。投稿は公開されます。運営が削除することがあります。」

### コメント一覧 `CommentList`

- 1 件: 1 行目 `ニックネーム · YYYY-MM-DD HH:mm`（ニックネーム 700、日付 mono `--ink-60`）、2 行目以降 本文（`white-space: pre-wrap`、`textContent` で描画、URL の自動リンク無し）。
- 区切りは `--rule` の破線 1px。アバター無し、返信無し、いいね無し。
- 最新 50 件。それ以上は表示しない（「もっと見る」も無い。フォーラムではない）。
- 劣化時: 「いま反応を受け付けていません。記事の内容には影響ありません。」の 1 行のみ。

### 原文ボックス `SourceQuote`

- `--rule` 1px 枠、内側余白 16px。見出し「原文」（h3 スタイル）。
- 引用は数十語まで、`"…"` で囲む、`font-style: normal`（日本語ではイタリックが崩れる）。
- 出典行: mono 14px `ドメイン/パス · YYYY-MM-DD · 原文を読む →`。

### 表 `DataTable`

- 罫線は水平のみ `--rule`。ヘッダ行は 700、下線 2px。
- 数字列は右寄せ mono。塗る数値は `<mark>` で `--marker`。
- モバイル（`< 48rem`）では各行をカードに畳み、`data-label` で列名を左に出す。

### ナビ `SiteNav`

- 製品 7 個を横一列。現在地は `--indigo` 文字 + 下線 2px。
- モバイルは `<details>` のハンバーガー。JS 不要。

## コピーの声

**案内所の人。** 丁寧だが短い。数字と日付を先に言う。断定する。分からないことは「未公表」と言う。

| 使う | 使わない |
|---|---|
| です・ます | だ・である、体言止めの連発 |
| 「無料は 1 日 n 本です」 | 「なんと無料でも使えちゃいます」 |
| 「2026-09-08 に確認しました」 | 「最新情報をお届け」 |
| 「円建て公式価格は未公表です」 | 「おそらく〜」「〜と思われます」 |
| 「原文を読む」 | 「詳しくはこちら」 |
| 「いま反応を受け付けていません」 | 「エラーが発生しました」 |
| 「非公式サイトです」 | 「ファンサイト」「応援サイト」 |

禁止語: 徹底解説、完全ガイド、最強、神、爆速、必見、まとめてみた、〜してみた、革命、衝撃。title と description にも適用。

title の型: `<製品> の <属性>（YYYY年M月時点）`。例: `Grok Imagine の動画生成制限（2026年9月時点）`。「翻訳」は入れない。

## ライト / ダーク

**ライト（紙）を唯一のプライマリにする。** 参考書は白い紙に印刷されている。ダークは v1 では作らない。

理由: `--marker` の蛍光黄はダーク背景で成立しない（黒地に黄色は「工事現場」になる）。ダークを作るならマーカーの概念ごと設計し直す必要があり、v1 の価値には無関係。`prefers-color-scheme: dark` でも紙のまま。フェーズ 3 以降、要望が出たら `--paper: #1C2230` / `--ink: #E8E9E4` / `--marker` を `#8A7A1E` 系の「蛍光ペンの裏写り」に落とした案を検討する。

## favicon / OGP

- favicon: `--paper` 地に `--stamp` の角丸枠 + 「非」1 文字（SVG）。小さくても判子に見える。
- OGP 共通画像 1 枚（1200×630）: `--paper` 地、左上に判子、中央に `Grok JP` と副題「ファンコミュニティ（非公式）」を BIZ UDPGothic 700 で組む。ロゴ無し、イラスト無し。記事ごとの生成はフェーズ 3 以降。

## 却下した案と理由

| 案 | 却下理由 |
|---|---|
| SaaS ランディング（ヒーロー + グラデーション + 3 カラムの特徴 + CTA） | 売るものが無い。読者は 30 秒で数字を知りたい。ヒーローは 1 スクロール分の遅延 |
| grok.com の模倣（黒地 + 白文字 + 幾何学的な X） | ブランドガイドライン抵触の疑いを自ら濃くする。非公式が公式に見えてはいけない |
| クリーム + テラコッタの「AI ブログ」既定色 | 2025〜26 年の AI 系ブログの 8 割がこれ。区別がつかない。「参照デスク」の冷静さと合わない |
| アシッドグリーン on 黒 | ハッカー風。非エンジニアの読者（Bot / Imagine ユーザー）を遠ざける。数字の可読性も落ちる |
| 紫グラデーション + ガラス（glassmorphism） | 「AI っぽさ」の記号。中身が薄く見える。CSS も重い |
| カードグリッドで全部並べる | 表の方が比較に強い。カードは 1 画面の情報密度を 3 分の 1 にする |
| Noto Sans JP | 無難で何の声も無い。Fontsource で読み込むなら BIZ UDPGothic の方が「参照デスク」に合う |
| システムフォントのみ | 最速だが匿名。数字の桁が揃わない。mono だけでも self-host する価値がある |
| ダークモード同時提供 | マーカーの設計が崩れる。v1 の価値に無関係 |
| アバター、返信、いいね、スレッド | フォーラムになる。オーナー決定で明確に対象外 |
| 記事ごとの OGP 画像 | 20,000 ファイル上限に効く。共通 1 枚で始める |
| Giscus 埋め込み | GitHub アカウント必須。CSP に iframe。オーナー決定で自前に |

## 実装メモ

- トークンは `src/styles/tokens.css` に置き、コンポーネントは変数だけ参照する。Hex をコンポーネントに直書きしない。
- `<mark>` のデフォルトスタイルを `--marker` に上書き。本文中の数字ハイライトは `<mark class="num">`。
- Fontsource の import は `Base.astro` 先頭で `@fontsource/biz-udpgothic/400.css` `/700.css` `@fontsource/ibm-plex-mono/400.css` `/500.css`。
- リアクションとコメントの JS は `src/scripts/widget.ts` 1 本。Astro の `<script>` でバンドル。インラインは CSP で禁止。
- 判子の傾きは `prefers-reduced-motion` に無関係（アニメーションではない）。
