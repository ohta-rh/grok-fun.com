## 何が変わったか

2026-10-21、Anthropic は Claude Duet を出しました。朝の要点を、自分から送ってくるアプリです。メールと予定を見て、返事の下書きまで始めます。クラウドに、自分用のコンピュータとブラウザがあります。アプリを閉じても、仕事は続きます。

発表の文です。「Today, we’re opening a research preview of Claude Duet, a new app where Claude works as a proactive agent.」まだ試験中の新しいアプリで、Claude が先に動く、という書き方です。全文は [Introducing Claude Duet](https://claude.com/resources/articles/claude-duet) です。始め方は [Get started with Claude Duet](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet) です。

## どこで使えて、いくら払うか

Claude Duet に今入れるのは、米国の Pro、Max、Ultra です。入口は順番待ちで、招待は何回かに分けて届きます。届く日は決まっていません。順番待ちのメールアドレスは、Claude のアカウントと、スマホの Apple か Google のアカウントで、同じものにします。Team と Enterprise は、まだ対象外です。あとから入れる、と始め方のページにあります。

始め方のページにあるのは、iPhone と Android の専用アプリと、claude.ai です。いつもの Claude のアプリとは別です。

2026-10-22 の [Claude の料金](https://claude.com/pricing) では、Pro は月 <span class="num">$20</span>、年払いなら月あたり <span class="num">$17</span>（先に $200）です。Max は月 <span class="num">$100</span> からです。カードでは、Pro の 5 倍か 20 倍かを選びます。FAQ では、その倍率は 5 時間ごとに使える量の話です。税は別です。同じカードの $100 と $200 は、月の API クレジットです。契約の月額は、ページの先頭にある月 $100 からです。

試験のあいだ、Claude Duet の追加料金はありません。対象は Pro、Max、Ultra です。使う分は、そのプランの分から減ります。5 時間で戻る分があるプランは、その分も減ります。週の分も減ります。始め方のページは、Claude のチャットと同じ基準で減る、と書いています。朝の要点も、数時間おきの確認も、その分に入ります。チャットだけのときより早く、上限に届くことがあります。発表のページは、普通の会話とは使い方が違う、と書いています。朝の確認も使う分に数えます。資金計画の表やスライドのような大きな仕事は、使う分がさらに増えます。

試験のあいだは、5 時間の分と週の分を一度に戻せる回数が決まっています。Pro は 3 回、Max と Ultra は 1 回です。1 回使うと、5 時間の分と週の分の両方が戻ります。使わない回数は 2026-12-15 に切れます。戻すのは、ウェブか Claude Desktop の Settings にある Usage からです。同じプランの分は、Claude Code も使います。

Grok Bot に新しく入る案内は、2026-10-22 の [x.ai/bot](https://x.ai/bot) にあります。Premium は月 <span class="num">$30</span> で、Grok Bot のコンピュータと、週の使用量が付きます。Super は月 <span class="num">$100</span> で、Premium の使用量の 3.5 倍です。Ultra は月 <span class="num">$200</span> で、Premium の使用量の 12 倍です。週の分を超えたあとは、トークンの定価で追加します。Premium、Super、Ultra、Teams、Enterprise にすでに入っている人には、Grok Bot が付いています。税は別です。

同じ日の [x.ai/pricing](https://x.ai/pricing) は、別の測り方です。週の分は、Grok と Cursor で共有します。Grok の中では、チャット、Imagine、Voice、Bot が同じ分から減ります。表の倍率は Plus と比べて、Premium が 4 倍、Super が 15 倍、Ultra が 50 倍です。Plus の月 <span class="num">$8</span> のカードに、Grok Bot はありません。Grok の API は、その分から減りません。API の定価で、別に払います。Bot のカードの 3.5 倍と、料金表の 15 倍は、書いてあるページが違います。

払う場所は <a href="/tips/free-vs-supergrok/">Heavy を解約して入り直した</a> に書いてあります。

2026-10-16 の [始め方](https://docs.x.ai/grok-bot/get-started) と、2026-10-07 の [概要](https://docs.x.ai/grok-bot/overview) は、まだ別の入り方を書いています。個人の有料 Cursor、Cursor Teams、繋いだ SuperGrok、SuperGrok Plus、SuperGrok Heavy です。今日の新規カードは、x.ai/bot の Premium からです。すでに入っている人の案内は、docs の方に残っています。

話す場所も、ページで違います。x.ai/bot の FAQ は、macOS か Windows のデスクトップと、iOS です。2026-10-07 の概要は、macOS、Windows、Linux、iOS、Android と書いています。2026-10-16 の始め方にあるデスクトップは、macOS、Windows、Linux です。2026-10-17 の [スマホの案内](https://docs.x.ai/grok-bot/mobile) は、iOS 18 以降と Android 9 以降です。

## 動き方

Claude Duet は、繋いだアカウントを数時間おきに見ます。ずっと見ていると、プランの分が早く減るからです。急ぎの用事は、見ていない間に届くことがあります。何を、どのくらいの間隔で聞くかは、自分で言えます。朝の要点は、メールと予定の中で、いちばん要るものだけです。

Claude Duet との会話は、一つの流れです。文字でも、録音した声でも送れます。話題ごとに別の会話も作れて、記憶は全部で共有します。仕事の進みと、自分の返事を待っているものは、一つの画面に並びます。終わった印を付けるのは、自分だけです。出来上がったファイルは、会話とは別の場所に置かれます。相手は一人の Claude Duet で、コンピュータの台数は案内にありません。自分用のクラウドコンピュータ、とだけあります。

送る前、払う前、署名する前、消す前に、何をするかを見せて、待ちます。承認してもできないのは、証券の売買、口座のあいだのお金の移動、他人のアカウントに入ることです。パスワードは、直接は見ません。

買うときは、Link（Stripe の財布）か Shop Pay です。買う前に聞いて、その買い物だけのカードで払います。本当のカード番号は渡しません。Link と Shop Pay を繋ぐのは、Claude Duet の画面の中です。アプリの接続一覧からではありません。

接続とプラグインは 6,000 を超えます。名前があるのは、Gmail、Slack、Google Calendar、Google Drive、QuickBooks、Stripe、HubSpot、Docusign、Calendly、Gusto、LinkedIn、Canva、Shopify です。Slack は制限付きです。Microsoft 365 は、まだ使えません。LinkedIn への掲載は、直して承認してからです。1Password でのサインインは、これからです。Grok Bot のアプリの数は、案内に無いので、数では比べません。入れる場所は、Connect apps です。

電話はかけません。ほかの人への SMS も送りません。承認すれば、繋いだアカウントからメールは送れます。

個人の用事、たとえば切符の予約は、仕事ほど得意ではない、と発表にあります。初期なので、メールの読み違えや、急ぎかどうかの判断違いは、あり得ます。製品ページの利用者の話は、Anthropic 側のエピソードです。測った結果としては扱いません。

モデルは Opus 5.5 です。選ぶ画面はありません。Claude Duet が、仕事の大きさに合わせて、考える量を決めます。今の Claude アカウントの記憶と、Skill と、繋いだアプリを持ってきます。プロジェクトの外の、過去のチャットも探せます。チャットを消すと、検索からも消えます。アプリの接続を外すと、その先は見に行きません。それまでの記憶は残ります。プロジェクトの全部と、自分のコンピュータのファイルは見えません。Claude の中の仕事は読めますが、変えられません。

## Grok Bot と並べる

Grok Bot で、話しかけていないあいだに動くものとして案内にあるのは、自分で置いた定期の仕事と、出来事で起動するよう自分で書いた規則です。2026-10-12 の [Skill と Routine](https://docs.x.ai/grok-bot/skills-routines-and-automations) です。定期の仕事は、1 体の Bot に 50 まで置けます。記録は新しい方から 20 件残ります。間隔は 5 分以上です。送る、買う、消す、公開する、動いているシステムを変える。この前には確認を求めなさい、と書いてあるのは、定期の仕事の書き方の章です。送る前の下書きを自分が見る、という文は、概要にあります。

2026-10-17 のスマホの案内では、Grok Bot のブラウザの仕事を自分のスマホで見て、パスワードや二要素や CAPTCHA のときは自分で操作を引き取り、終わったら Bot に返します。Claude Duet は、ブラウザを見ることも、自分で引き取ることもできません。ノートパソコンを閉じても、クラウドの仕事は、どちらも続きます。

コンピュータは、同じアカウントの Grok Bot が 1 台を共有します。ファイルと、ブラウザのログインは分かれません。この話は <a href="/tips/grok-bot-cloud-computer/">クラウドにコンピュータがある</a> に書いてあります。複数の Bot が同時に動き、互いにメッセージを送れます。チャット、Bot、Build が別の道具だという話は <a href="/tips/bot-build-chat-map/">チャット、Grok Bot、Grok Build は別の道具</a> に書いてあります。

モデルの案内も違います。2026-10-17 の [設定](https://docs.x.ai/grok-bot/settings-and-notifications) は、モデルは Cursor が選ぶ、選ぶ画面は無い、と書いていました。2026-11-09 の同じページは、選ぶのは Grok Bot で、選ぶ画面は無い、と書いています。2026-11-09 の [FAQ](https://docs.x.ai/grok-bot/faq) は、仕事ごとにモデルが変わり、名前は出ない、と書いています。Opus 5.5 に回しても、トークンごとの金額は変わらない、とも書いています。2026-10-07 の開発者の投稿は、本体は Opus 5.5 で広がっている、と書きました。投稿の話は <a href="/news/bot-opus/">Grok Bot は、仕事ごとにモデルを選ぶ</a> です。

声も違います。Claude Duet の声は、録音したメッセージです。Grok Bot の概要にある声は、音声の会話と、音声メモです。
