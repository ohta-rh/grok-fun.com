## 何が変わったか

2026-10-12、SpaceXSI は The X Subscription を出しました。Grok と、Grok Bot と、Cursor と、X Premium が、1つの契約です。投稿の時刻は 2026-10-12 23:08 UTC で、日本時間では 2026-10-13 8:08 です。全文は [SpaceXSI の投稿](https://x.com/SpaceXSI/status/2109783335296008414) です。発表は [Introducing The X Subscription](https://x.ai/news/x-subscription) です。

新規の人は、この日からこの契約です。今の SuperGrok、Cursor、X Premium は、値段も中身もそのまま残ります。切り替える操作は、請求の設定に出たら使えます。全員に同時には出ません。

<strong>新規は1つの月額です。今の契約は、切り替えない限り残ります。</strong>いちばん上の図に書いたのは、そのことです。

## いくら払うか

[x.ai/pricing](https://x.ai/pricing) と [docs の料金](https://docs.x.ai/x-subscription/pricing) で、月額は同じです。

<div class="table-scroll">

| プラン | 月額 |
|---|---|
| Free | <span class="num">$0</span>。使える量は Limited |
| Plus | <span class="num">$8</span>。Bot は無い |
| Premium | <span class="num">$30</span>。使える量は Plus の 4 倍。Bot あり |
| Super | <span class="num">$100</span>。使える量は Plus の 15 倍 |
| Ultra | <span class="num">$200</span>。使える量は Plus の 50 倍 |

</div>

年払いも、同じ docs にあります。Plus は年 <span class="num">$80</span>（月あたり $7）、Premium は年 <span class="num">$300</span>（月あたり $25）、Super は年 <span class="num">$1000</span>（月あたり $84）、Ultra は年 <span class="num">$2000</span>（月あたり $167）です。税は別です。

発表によると、Premium の中身は SuperGrok と Cursor Pro と X Premium+ です。この 3 つは、以前は別々に払って月 $90 でした。

Grok Bot は Premium、Super、Ultra に入っています。Plus には入っていません。Plus で使えるモデルは Grok だけです。ほかの会社のモデルは Premium からで、プランの分とは別に、API の定価で払います。

使える量は、週が変わると戻ります。Grok と Cursor で同じ分を使います。Grok の中では、チャット、Imagine、Voice、Bot、API です。製品によって減る量は違います。1日にたくさん使っても、翌週には戻るので、月のあいだずっと使えなくなるわけではありません。その週の分を使い切ったら、次の週を待つか、追加のクレジットを買います。Cursor で他社のモデルを使う分は、プランに含まれません。1 回目から、別のクレジットで払います。

Ultra は、新しい製品とモデルをいちばん早く使えます。

チームは、Premium がシート月 <span class="num">$30</span>、Super がシート月 <span class="num">$100</span>、Ultra がシート月 <span class="num">$200</span> です。1シートの量は、個人の同じ種類と同じです。Plus はチームにありません。同じチームで、シートの種類を混ぜられます。前の Cursor Teams よりシートの単価が低く、コーディングの使用量は 3 倍です。

## どうするか

残す人は、何もしません。

移る人は、Web でやります。今払っている人は、スマホアプリから始めても Web に飛ばされます。まだ何も払っていない人は、Grok、X、Grok Bot、Cursor のアプリから新規に入れます。その支払いは App Store か Google Play です。

<div class="table-scroll">

| 今の支払い | 始めるページ |
|---|---|
| Cursor | <a href="https://cursor.com/unify">cursor.com/unify</a> |
| Grok | grok.com の設定の請求。または <a href="https://accounts.x.ai/unify">accounts.x.ai/unify</a> |
| X だけ | x.com の契約設定。Cursor も払っているなら、上の Cursor の行です |
| チーム | <a href="https://cursor.com/unify/team">cursor.com/unify/team</a>。管理者だけ |

</div>

Cursor を払っている人は、cursor.com/unify で Get started を押します。足すアカウントを選んで、プランを選んで、支払います。X だけを払っていて Cursor の有料が無い人は、x.com の契約設定からで足ります。

チームは、Cursor の管理者かオーナーが始めます。Grok のチームも入れるなら、そのチームの請求の管理者でもある必要があります。メンバーは始められません。

終わったあとの請求は、[grok.com/dashboard](https://grok.com/dashboard) です。

切り替えに入れた契約は、使っていない日数の分が、元の支払いへ別に戻ります。新しい契約の金額からは引きません。料金のページでは、新しい契約は満額で、すぐ始まります。発表の FAQ では、変更はすぐに入って、日割りになります。Ultra の支払い画面は、初月だけ 50% オフでした。返金が口座に出るまで、数日かかることがあります。自分で先に解約した分は、この自動の日割りとは別です。grok.com で払った SuperGrok は、FAQ のフォームから返金を申し込みます。通るかどうかは、審査で決まります。

Ultra の支払い画面を開いているあいだも、SuperGrok Heavy は「レガシー」と「アクティブ」のままでした。次の請求サイクルは 2026-10-17 に開始します、と出ていました。これは解約の日ではありません。支払い画面を開いただけでは、Heavy は止まりません。このアカウントは、その Heavy を解約してから、新しいプランで契約し直しました。公式の手順では、支払いを終えると、選んだ古い契約が止まります。

同じ日、Ultra に移す画面には、Apple Pay とクレジットカードが並んでいました。この画面の Apple Pay も、クレジットカードも、grok.com の支払いです。iPhone の設定の定期購入ではありません。税込みで、初月は <span class="num">¥17,400</span>、その後は月 <span class="num">¥34,800</span> でした。50% オフは、初月の 1 か月だけでした。公式の月額は $200 です。上の円の金額は、2026-10-13 にこの画面に出ていたものです。自分の画面に出る金額で確認します。

止め方は、払った場所で違います。このアカウントは、上の図のサブスクリプションの画面で SuperGrok Heavy を解約してから、新しいプランで契約し直しました。

- 移らずにやめる人も、grok.com のクレジットカード払いなら、上の図のサブスクリプションの画面で止めます
- Cursor を iPhone か iPad の App Store で払っている人は、運営側では止められません。設定の定期購入で止めて、返金は Apple に頼みます。切り替えのあと、メールが来ます。届かなければ迷惑メールも見ます
- Grok、Grok Bot、X Premium を App Store で払っている人は、運営が解約して、Apple に未使用分の返金を頼みます。金額は Apple が決めます。断られると更新は止まって、払った期間の終わりまでは残ります
- Grok、Grok Bot、X Premium を Google Play で払っている人は、切り替えたあと Play の定期購入を見ます。更新が残っていたら、そこで止めます
- 贈られた X Premium と、Apple のファミリー共有は、解約も返金もされません

一度まとめると、戻せません。サポートも戻せません。メールアドレスが違っていてもつなげられます。確定の前に、つなぐアカウントを確認します。X は個人のアカウントだけ足せます。1つの X は、1つの Grok にだけつながります。個人とチームは、別々にまとめます。未払いの請求が残っていると、まとめられません。先に払います。個人の Cursor で、リクエスト数で数える古い料金のままの人は、先にダッシュボードで Opt In to New Pricing を押してから、まとめます。チームで古い料金のままのときは、その画面からはまとめられません。サポートに連絡します。

年払いは、切り替えない限り、払った期間の終わりまで残ります。残っている人をいつ移すか、発表に日程はありません。移すときは、事前に知らせます。請求の設定に、期間限定の案内が出ることがあります。中身は、自分の画面に出ている文面です。

手順のページは [How to unify accounts](https://docs.x.ai/x-subscription/unify-accounts) です。誰がまとめられるかは [Unification eligibility](https://docs.x.ai/x-subscription/eligibility) です。

## 前の契約

2026-10-07 までは、grok.com の SuperGrok が月 $30、SuperGrok Plus が月 $100、Cursor の Pro が月 $20 で、別々の契約でした。X Premium に入っても、grok.com は無料のまま、が普通でした。その契約は、今入っている人には残ります。前のプランは、新規の申込には出ません。

SuperGrok Heavy の月額は、2026-10-07 の料金ページの先頭にありませんでした。今の料金ページの先頭にも、Heavy という名前はありません。Ultra の月 $200 は、Heavy の月額ではありません。

移し方の詳細は、<a href="/tips/free-vs-supergrok/">Heavy を解約して入り直した</a>に書きました。チャットの Heavy と、払う Heavy の違いは、<a href="/tips/expert-and-heavy/">Heavy は機能でも、プランでもある</a>です。

## よくある取り違え

- 「今の SuperGrok が、今日消える」: 残ります。新規の申込が、新しい契約です
- 「Plus の月 $8 にも Bot が付く」: Bot は Premium、Super、Ultra です
- 「Ultra の月 $200 は、SuperGrok Heavy の月額」: 別の名前です。Heavy の月額は、2026-10-13 の料金ページの先頭にありません
- 「切り替えると、日割りが新しい請求から引かれる」: 使っていない日数の分は、元の支払いへ別に戻ります。料金のページでは新しい契約は満額です。発表の FAQ では日割りです。Ultra の支払い画面は、初月だけ 50% オフでした
- 「一度解約して入り直すのは、手順に無い」: このクレジットカードの SuperGrok Heavy は、解約してから新しいプランで契約し直せました。支払い画面を開いても、「レガシー」と「アクティブ」のままでした
- 「自分で解約しても、切り替えと同じ日割りが自動で戻る」: 切り替えに入れた契約は、使っていない日数の分が自動で戻ります。grok.com の SuperGrok を自分で止めた分は、FAQ から返金を申し込みます。通るかどうかは、審査で決まります
- 「クレジットカードなのに、iPhone の設定で解約する」: grok.com のクレジットカードなら、サブスクリプションの画面で止めます。iPhone の設定で止まるのは、App Store の定期購入です
- 「Apple で Cursor を払っていても、運営が止めてくれる」: Cursor の App Store 課金は、自分で止めます
- 「X Premium のまま、grok.com も有料になる」: 切り替えない限り、別の契約のままです
- 「まとめたあと、また別々に戻せる」: 一度まとめると戻せません
