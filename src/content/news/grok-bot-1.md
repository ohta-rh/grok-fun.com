## 何が変わったか

2026-11-02、SpaceXSI は Grok Bot 1.0 を出しました。発表は [Introducing Grok Bot 1.0](https://x.ai/news/grok-bot-1-0) です。

チームの人と、同じ Bot を使えます。Slack、Microsoft Teams、ビデオ通話にも呼べます。頼まれる前に、やったほうがいい仕事を見つけて提案します。ブラウザの操作と、書類やスライドを作る仕事は、前より失敗しにくくなった、と発表にあります。同じ仕事に使う計算の量も減ったそうです。どれだけ減ったかの数字は、発表にありません。

<strong>Imagine のページは、まだ開けます。公式の新しい話は Grok Bot 1.0 です。</strong>いちばん上の図に書いたのは、そのことです。

2026-11-13、The Information は、会社が Imagine の担当を約 <span class="num">60</span> 人減らし、少しだけ残した、と報じました。The Information の X アカウントが、[2026-11-13 に投稿](https://x.com/theinformation/status/2121279457084244122)しています。原文は “laid off roughly 60 employees working on Grok Imagine, leaving just a handful to maintain the product.” です。The Information の Grok のページに出ている見出しは “Elon Musk’s AI Group Guts Grok Video Generation Team” で、書いたのは Aaron Tilley、Claudia Chong、Juro Osawa です。記事の本文は有料です。このメモは、本文を読まずに書いています。

[ニュース一覧](https://x.ai/news) の先頭は、2026-11-16 も Grok Bot 1.0 です。その一覧に、動画を止める案内はありません。2026-11-16、東京から [grok.com/imagine](https://grok.com/imagine) を見ると、ページは残っていました。

## どのプランで使えて、いくら払うか

動画の作り方は、今までと同じです。<a href="/tips/imagine-video/">先に絵を出してから、動きを一つ書く</a>に書いてあります。動画の長さと解像度の上限は、自分のプラン画面で見てください。TIPS に書いた上限は 2026-09-17 の x.ai/grok の数字で、今回は確かめ直していません。

自分の Bot は、Premium からです。2026-11-16 の [料金](https://docs.x.ai/x-subscription/pricing) では、Plus は月 <span class="num">$8</span> で Bot は無く、Premium は月 <span class="num">$30</span>、Super は月 <span class="num">$100</span>、Ultra は月 <span class="num">$200</span> です。払う場所の話は <a href="/tips/free-vs-supergrok/">Heavy を解約して入り直した</a>にあります。

<div class="table-scroll">

| やりたいこと | 2026-11-16 の案内 |
|---|---|
| 動画を出す | Imagine のページは残っている |
| 自分の Bot | Premium から。月 <span class="num">$30</span> |
| 同じ Bot をチームで | Team と Enterprise。Premium シートは月 <span class="num">$30</span> |
| Bot を会議に入れる | Team、Enterprise、Ultra。個人の Ultra は月 <span class="num">$200</span> |
| 米国の店へ電話 | アプリ。かける前に、相手を見て承認 |

</div>

チームで同じ Bot を使うのは、Team と Enterprise です。2026-11-02 の発表に、そうあります。シートの金額は、2026-11-16 の料金です。Premium シートは月 <span class="num">$30</span>、Super シートは月 <span class="num">$100</span>、Ultra シートは月 <span class="num">$200</span> です。料金のページに、Enterprise の金額は載っていません。

会議は、Team、Enterprise、Ultra です。2026-11-11 の [会議の案内](https://docs.x.ai/grok-bot/meetings) でも同じです。Google Meet、Zoom、Microsoft Teams のリンクを渡して、参加を承認します。Enterprise は、管理者が設定で会議をオンにします。個人の Premium に、会議は書いてありません。個人の Ultra でも、Bot を会議に入れられます。

電話は、米国だけです。2026-11-16 の [会話の案内](https://docs.x.ai/grok-bot/chat-and-collaboration) では、Bot が店に電話して、予約や注文の様子を知らせます。最初に、同意を一つ求められます。かける相手は、米国の事業者と、電話を受けてよいと言った人だけにする、という内容です。かける前に、相手の名前が出て、Call か Cancel を選びます。使えるのは、デスクトップとスマホのアプリです。日本の店にかける手順は、そのページにありません。2026-11-15、Musk は [2026-11-14 の動画](https://x.com/iiiichigo_chan/status/2121664393725227299)を引いて、[“Try Grok @Bot”](https://x.com/elonmusk/status/2121770874885845044) と書きました。日本の空港から、Bot が航空会社に電話する動画です。動画の投稿には、架空の航空会社を使った作り物だ、という注記が付いています。

Bot が使うコンピュータの話は、<a href="/tips/grok-bot-cloud-computer/">クラウドにコンピュータがある</a>に書きました。チャットと Bot の分け方は、<a href="/tips/bot-build-chat-map/">チャット、Grok Bot、Grok Build は別の道具</a>に書きました。

## 公式が書いたこと

2026-11-02 の発表には、こうあります。“Bots can recognize work that needs to be done and offer to take it on.” やったほうがいい仕事を見つけて、引き受けると申し出る、という文です。

2026-11-11 の [Bot が自分から提案する機能の案内](https://docs.x.ai/grok-bot/initiative) には、Bot は待つだけではない、とあります。主な Bot（サイドバーで星が付いている Bot）が仕事を見つけて提案します。アプリの接続が切れたときも、チャットで知らせます。先に提案して、こちらがよいと言うと、頼んだ仕事と同じように進めます。危ない操作の前には、聞きます。Team Bot は、主な Bot にはなれません。

2026-11-09、Musk は、Bot のエンジニアのチームと集まって見直しをした、と書きました。原文は [その投稿](https://x.com/elonmusk/status/2119617455102333206) の “Just did a round table review with the Grok @Bot engineering team.” です。
