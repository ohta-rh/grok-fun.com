## 何が変わったか

2026-09-29、サンフランシスコの DevDay で、OpenAI は dots を出しました。ChatGPT の中に置いて、仕事を任せておけるエージェントです。頭脳は GPT-6 Astra だと、発表のページに書いてあります。dot はクラウドに専用のコンピュータとブラウザを持ち、あなたが繋いだアプリを使います。

OpenAI は、こう書いています。「Dots are remarkably capable, always-on agents built to handle everything.」何でも任せられるように作った、いつも動いているエージェントだ、という書き方です。全文は [Introducing dots](https://openai.com/index/introducing-dots/) です。同じ日の [DevDay 2026 Recap](https://openai.com/index/devday-2026-recap/) にも、短い紹介があります。

いちばん上の図は、コンピュータの分け方です。<strong>dot は 1 体が 1 台です。</strong>今、プランに入るのは最初の 1 体なので、手元に増える台数は 1 台です。Grok Bot は、同じアカウントの Bot が 1 台を共有します。画面は Bot ごとに分かれます。ファイルとログインは分かれません。

日本から使う人は、まず自分のプラン画面を見ます。

dot を作れるのは、ChatGPT のデスクトップアプリか、パソコンのブラウザです。[Help Center](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot) は、スマホのアプリでは作れない、スマホのブラウザには対応していない、と書いています。作ったあとは、スマホのアプリから話せます。Windows のデスクトップアプリでも作れます。

対象は、発表のページでは Pro、Business Premium、Enterprise です。Help Center はもう少し細かいです。Pro は、欧州経済領域とスイスと英国を除く市場へ、順に届きます。Business Premium は、ChatGPT が対応している地域の全部です。Enterprise と Edu と Healthcare はベータで、管理者がオンにするまでオフです。届くまで数日かかることがある、とも書いてあります。Pro の除外に、日本は書いてありません。

料金は、2026-10-01 に開いた [Pro の Help Center](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) の数字です。Pro は 3 段で、月 <span class="num">$100</span>、月 <span class="num">$200</span>、月 <span class="num">$500</span> です。$500 の段は Pro 500 で、[2026-09-29 のリリースノート](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) が新しい段として書いています。Ultrafast が付くのは、Pro の中ではこの段だけです。dots のページは「Pro」とだけ書き、100 と 200 と 500 のどれか、とは分けていません。

Business の Premium 席は、[2026-08-10 の発表](https://openai.com/index/premium-seats-chatgpt-business/) と、2026-10-01 に開いた [Business の FAQ](https://help.openai.com/en/articles/8542115-chatgpt-business-general-faq) では、月払いで 1 人 <span class="num">$125</span>、年払いなら 1 人あたり月 <span class="num">$100</span> です。Standard 席は月 <span class="num">$25</span>、年払いなら月 <span class="num">$20</span> です。dots の対象に書いてあるのは Business Premium で、Standard 席とは書いてありません。案内の通貨はドルです。日本の契約画面に出る数字は、その画面で見てください。

最初の 1 体は、Pro か Business Premium に入っていて、追加の月額は無い、と発表にあります。dot との会話は、ChatGPT の使用量に入りません。深い仕事には枠があり、公開から 1 か月は枠が広い、ともあります。枠の数字は、そのページにありません。dot に Codex や ChatGPT Work の仕事を始めさせると、その仕事はいつもの使用量に入ります。dot を増やすこと、速さを上げること、1 か月に任せられる量を増やすことは、今後だ、と書いてあります。

Grok Bot は別のアプリです。アプリは [x.ai/bot](https://x.ai/bot) から入れます。サインインは Cursor のアカウントです。2026-10-01 の [cursor.com/pricing](https://cursor.com/pricing) では、個人の有料プランが月 <span class="num">$20</span> で、Grok Bot access と書いてあります。同じカードに Pro、Pro+、Ultra の切り替えがあります。Teams は 1 人あたり月 <span class="num">$40</span> で、こちらにも Grok Bot access とあります。Pro+ と Ultra の金額は、その切り替えの中に出ます。

個人の SuperGrok、SuperGrok Plus、SuperGrok Heavy、X Premium+ を、Cursor のアカウントに結んでも使えます。[プラン案内](https://cursor.com/help/grok-bot/plans) は、結んでも Cursor のプランの使用量とは足し算にならない、と書いています。使用量は週で戻ります。週の分を使い切ったあとは、オンデマンドをオンにしていれば Cursor 経由で続けられます。その分は、月の上限に数えられます。数字はプラン画面に出ます。grok.com のチャットの枠とは別です。コンピュータは、[セキュリティ FAQ](https://docs.x.ai/grok-bot/security-faq) によると、今は米国で動きます。

払う場所の話は、<a href="/tips/free-vs-supergrok/">やりたいことで払う場所が決まる</a>に、前から書いてあります。

## OpenAI が書いた動き

dot は、話しかけていないあいだも、繋いだアプリを見て、助けられそうなことを探します。OpenAI はこの動きを proactive research と呼んでいます。<strong>このあいだに使える道具は、読むだけです。</strong>メッセージを送る、アプリの中身を変える、ブラウザやコンピュータを操作する、はやりません。懸念を検知したら、仕事を止める、ともあります。

話せる場所は、ChatGPT と Slack と Teams です。テキストメッセージは、発表ではこれからです。Help Center には、米国の Pro で限定ベータ、Business と Enterprise には無い、とあります。電話は、こちらからかけられます。dot の方からかけてくることは、公開の時点ではありません。

プラグインで、4,000 を超えるアプリに繋げる、と発表にあります。Grok Bot の概要に、同じ数え方の数字は見当たりません。数では比べません。

パスワードの変更のような作業は、人がやります。対応しているサイトへのサインインは、保存したパスワードを、モデルに見せずに使える、とあります。自分のパソコンへの接続は、最初はオフです。デスクトップアプリで許可すると、ファイルに触れます。取り消すまで、その許可は残ります。

ルールの画面名は Custom Rules です。聞かずにやる、事前に頼んだときだけやる、やる前に聞く、自分に渡す、から選びます。

学習については、Business、Enterprise、Edu の中身は、標準ではモデルの改善に使わない、とあります。個人のプランは、会話と仕事を改善に使うかを自分で選べます。proactive research と、dot が自分用に残すメモは、直接の学習には使わない、ともあります。

specialist dots は、会社の中で一つの仕事を受け持つ dot です。身元と認証情報は、会社が別に持ちます。今は、対象を絞った企業向けの試験です。Microsoft の Agent 365 と繋ぐ作業も、これからです。

2026-10-01 に、両方の案内を開きました。テストの点を並べた表は、2026-09-29 の発表にありません。

頭脳の名前から違います。dots は GPT-6 Astra と書いてあります。Grok Bot の [設定のページ](https://docs.x.ai/grok-bot/settings-and-notifications) は、モデルは Cursor が選び、選ぶ画面は無い、と書いています。Grok の何番、とは案内にありません。

コンピュータも違います。発表の安全の節は、各 dot が自分のクラウドコンピュータで動く、と書いています。今もらえるのは最初の 1 体です。Grok Bot の [FAQ](https://docs.x.ai/grok-bot/faq) は、アカウントの Bot 全部が 1 台を使う、と書いています。画面は Bot ごとにあります。ただ、画面の分かれ目は秘密の境界ではありません。ファイルも、ブラウザのログインも、コマンドの認証情報も共有です。ログインを分けたい仕事は、Cursor のユーザーを分けます。この話は <a href="/tips/grok-bot-cloud-computer/">クラウドのコンピュータは 1 台</a> に書いてあります。

始め方も違います。dots には、読み取りだけの proactive research という名前があります。Grok Bot の [概要](https://docs.x.ai/grok-bot/overview) と、[Skill と Routine](https://docs.x.ai/grok-bot/skills-routines-and-automations) のページに、同じ名前のモードは見当たりません。話しかけていないあいだに動くのは、すでに頼んだ仕事、自分で置いた Routine、Slack や GitHub の出来事で起動するよう自分で書いた規則です。Routine は、1 体の Bot に 50 までです。直近の実行記録は 20 件です。

何体置けるかも違います。Grok Bot は、今すでに複数の Bot が同時に動いて、互いにメッセージを送れます。グループの会話で、仕事を渡すこともできます。dots は、最初の 1 体がプランに入り、増やすのは今後です。会社向けの specialist dots は、別の試験です。

自分のパソコンの触れ方も違います。dots は、許可すると取り消すまで触れます。Grok Bot の標準は、そのたびに聞く、です。クラウドの仕事は、どちらもノートパソコンを閉じても止まりません。

使える端末も違います。Grok Bot の概要は、macOS、Windows、Linux、iPhone、iPad、Android と書いています。dot を新しく作るのは、パソコンの ChatGPT です。

## 8 月 11 日に、先に書いてあったこと

Grok Bot の公開は 2026-08-11 です。原文は [Introducing Grok Bot](https://x.ai/news/introducing-grok-bot) です。その日の文は、Bot はクラウドのコンピュータを共有する、と書いています。複数の Bot が同時に動き、グループの会話で仕事を渡す、ともあります。チャット、Bot、Build が別の道具だという話は <a href="/tips/bot-build-chat-map/">3 つの道具</a> に書いてあります。

同じページに、こうあります。「Over time they become more proactive, picking up work before you need to ask and knowing when something needs your attention.」時間が経つと、頼む前に仕事を拾う、という書き方です。読み取りだけ、という制限は、その文にはありません。

その日の料金の文には、Grok Bot の使用量は Grok と Cursor のプランとは別で、渡した仕事は今の使用量を減らさない、とあります。2026-10-01 のプラン案内は、週で戻る使用量のあと、オンデマンドは Cursor 経由で、月の上限に数えられる、と書いています。出した日の文と、今の案内は、ここがずれています。今の払いは、プラン案内の方です。

## 第三者は Muse と並べた

The Verge は 2026-09-29 に、dots を Meta の Muse と比べています。Muse は無料で、dots は有料のプランから、とその記事は書いています。Muse の中身は、このメモでは確かめていません。このサイトの読者が並べる相手は、Grok Bot です。

ファンとして残る理由は、今すでに Bot を複数走らせて、1 台のコンピュータでファイルを渡せることです。繋いだアプリを、読み取りだけで先に調べておいてほしい人には、dots の方が案内が具体的です。点で勝った、負けた、は、2026-09-29 の材料からは言えません。

## どうするか

すでに ChatGPT の Pro か、Business の Premium 席の料金を払っていて、繋いだアプリの先回りが要るなら、パソコンの ChatGPT を開いて、dot が届いているかを見ます。Plus にも、Go にも、Free にも、Business の Standard 席にも、対象の文はありません。

名前の付いた Bot を今すぐ複数走らせて、ファイルを共有させたいなら、Grok Bot のままです。grok.com の予約と、Bot の Routine は別の機能です。予約の話は <a href="/tips/grok-automations/">時刻で回す仕事</a> に書いてあります。

どちらかを解約する理由には、この発表だけではなりません。請求は、別々の会社から来ます。深い仕事の枠の数字は、OpenAI のページに無いので、画面に出るまで金額の想像はしません。

パスワードは、どちらの会話にも貼りません。
