## 何が変わったか

2026-09-29、サンフランシスコの DevDay で、OpenAI は dots を出しました。ChatGPT の中に置いて、仕事を任せておけるエージェントです。頭脳は GPT-6 Astra だと、発表のページに書いてあります。dot は、クラウドに専用のコンピュータとブラウザがあります。使うのは、自分が繋いだアプリです。

OpenAI は、こう書いています。「Dots are remarkably capable, always-on agents built to handle everything.」何でも任せられるように作った、いつも動いているエージェントだ、という書き方です。全文は [Introducing dots](https://openai.com/index/introducing-dots/) です。同じ日の [DevDay 2026 Recap](https://openai.com/index/devday-2026-recap/) にも、短い紹介があります。

いちばん上の図は、コンピュータの分け方です。<strong>dot は 1 体が 1 台です。</strong>今、プランに入るのは最初の 1 体なので、使える台数は 1 台です。Grok Bot は、同じアカウントの Bot が 1 台を共有します。画面は Bot ごとに分かれます。ファイルとログインは分かれません。

日本から使う人は、まず自分のプラン画面を見ます。

dot を作れるのは、ChatGPT のデスクトップアプリか、パソコンのブラウザです。[Help Center](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot) によると、スマホのアプリからも、スマホのブラウザからも作れません。作ったあとは、スマホのアプリから話せます。Windows のデスクトップアプリでも作れます。

対象は、発表のページでは Pro、Business Premium、Enterprise です。Help Center はもう少し細かいです。Pro は、欧州経済領域とスイスと英国以外から、順に使えるようになります。Business Premium は、ChatGPT が使える地域ならどこでも対象です。Enterprise と Edu と Healthcare はベータで、管理者が許可するまで使えません。届くまで数日かかることがあります。Pro の対象外に、日本は入っていません。

料金は、2026-10-01 に開いた [Pro の Help Center](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) の数字です。Pro は 3 種類で、月 <span class="num">$100</span>、月 <span class="num">$200</span>、月 <span class="num">$500</span> です。$500 のものは Pro 500 で、[2026-09-29 のリリースノート](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) に、新しく加わったと書いてあります。Ultrafast が付くのは、Pro の中ではこれだけです。dots の案内には、Pro とまとめて書いてあります。$100 と $200 と $500 のどこまで含むかは、そのページからは読めません。

Business の Premium シートは、[2026-08-10 の発表](https://openai.com/index/premium-seats-chatgpt-business/) と、2026-10-01 に開いた [Business の FAQ](https://help.openai.com/en/articles/8542115-chatgpt-business-general-faq) では、月払いで 1 人 <span class="num">$125</span>、年払いなら 1 人あたり月 <span class="num">$100</span> です。Standard シートは月 <span class="num">$25</span>、年払いなら月 <span class="num">$20</span> です。dots が入るのは Premium シートです。案内の金額はドル建てです。日本の契約画面に出る数字は、その画面で見てください。

最初の 1 体は、Pro か Business Premium の料金に含まれていて、追加の月額はかからない、と発表にあります。dot との会話は、ChatGPT の使用量に入りません。時間のかかる重い仕事には枠があり、公開から 1 か月は枠が広い、ともあります。枠の数字は、そのページにありません。dot に Codex や ChatGPT Work の仕事を始めさせると、その仕事はいつもの使用量に入ります。dot を増やすこと、速さを上げること、1 か月に任せられる量を増やすことは、これからだ、と書いてあります。

Grok Bot は別のアプリです。アプリは [x.ai/bot](https://x.ai/bot) から入れます。Cursor のアカウントでサインインします。2026-10-01 の [cursor.com/pricing](https://cursor.com/pricing) では、個人の有料プランが月 <span class="num">$20</span> で、Grok Bot access と書いてあります。同じ場所で、Pro、Pro+、Ultra を切り替えられます。Teams は 1 人あたり月 <span class="num">$40</span> で、こちらにも Grok Bot access とあります。Pro+ と Ultra の金額は、切り替えると出ます。

個人の SuperGrok、SuperGrok Plus、SuperGrok Heavy、X Premium+ を、Cursor のアカウントに繋いでも使えます。[プラン案内](https://cursor.com/help/grok-bot/plans) には、Cursor のプランをすでに払っている人は、繋いでも使える量は増えない、と書いてあります。使える量は、週が変わると元に戻ります。その週の分を使い切ったあとは、オンデマンドにしていれば Cursor 経由で続けられます。その分は、月の支払いの上限の中に入ります。数字はプラン画面に出ます。grok.com のチャットの枠とは別です。コンピュータは、[セキュリティ FAQ](https://docs.x.ai/grok-bot/security-faq) によると、今は米国で動きます。

払う場所の話は、<a href="/tips/free-vs-supergrok/">やりたいことで払う場所が決まる</a>に、前から書いてあります。

## OpenAI が書いた動き

dot は、話しかけていないあいだも、繋いだアプリを見て、助けられそうなことを探します。OpenAI はこの動きを proactive research と呼んでいます。<strong>このあいだに使える道具は、読むだけです。</strong>メッセージは送れません。アプリの中身も変えられません。ブラウザやコンピュータも操作できません。おかしな動きを見つけたら、その仕事を止めます。

話せる場所は、ChatGPT と Slack と Teams です。テキストメッセージは、発表ではこれからです。Help Center では、米国の Pro だけの限定ベータで、Business と Enterprise は入っていません。電話は、こちらからかけられます。公開の時点では、dot の方から電話は来ません。

プラグインで、4,000 を超えるアプリに繋げる、と発表にあります。Grok Bot の概要には、アプリの数は出ていません。数では比べません。

パスワードの変更のような作業は、人がやります。対応しているサイトには、保存したパスワードでサインインできます。パスワードはモデルには見えません。自分のパソコンへの接続は、最初は切れています。デスクトップアプリで許可すると、ファイルを開けます。取り消すまで、その許可は残ります。

ルールの画面名は Custom Rules です。聞かずにやる、事前に頼んだときだけやる、やる前に聞く、自分に回してもらう、の 4 つから選びます。

学習については、Business、Enterprise、Edu のデータは、設定を変えなければモデルの改善に使わない、とあります。個人のプランは、会話と仕事を改善に使うかを自分で選べます。proactive research と、dot が自分用に残すメモを、学習のデータとしてそのまま使うことはありません。

specialist dots は、会社の中で一つの仕事を受け持つ dot です。その dot 専用のログインを、会社が別に用意します。今は、一部の会社だけで試しています。Microsoft の Agent 365 と繋ぐ作業も、これからです。

2026-10-01 に、両方の案内を開きました。テストの点を並べた表は、2026-09-29 の発表にありません。

頭脳の名前から違います。dots は GPT-6 Astra と書いてあります。Grok Bot の [設定のページ](https://docs.x.ai/grok-bot/settings-and-notifications) では、モデルは Cursor が選びます。選ぶ画面はありません。Grok のバージョン番号も、案内には出ていません。

コンピュータも違います。発表の安全の節には、各 dot が自分のクラウドコンピュータで動く、と書いてあります。今プランに入るのは最初の 1 体です。Grok Bot の [FAQ](https://docs.x.ai/grok-bot/faq) には、アカウントの Bot 全部が 1 台を使う、と書いてあります。画面は Bot ごとにあります。ファイルも、ブラウザのログインも、ターミナルのログインも、同じ台の中です。ログインを分けたい仕事には、Cursor のユーザーを別に用意します。この話は <a href="/tips/grok-bot-cloud-computer/">クラウドのコンピュータは 1 台</a> に書いてあります。

始め方も違います。dots では、読み取りだけで先に調べる動きに、proactive research という名前が付いています。Grok Bot の [概要](https://docs.x.ai/grok-bot/overview) と、[Skill と Routine](https://docs.x.ai/grok-bot/skills-routines-and-automations) のページに、これに当たる動きは見当たりません。話しかけていないあいだに動くのは、すでに頼んだ仕事、自分で置いた Routine、Slack や GitHub の出来事で起動するよう自分で書いた規則です。Routine は、1 体の Bot に 50 までです。実行の記録は、新しい方から 20 件まで残ります。

何体置けるかも違います。Grok Bot は、今すでに複数の Bot が同時に動いて、互いにメッセージを送れます。グループの会話で、仕事を渡すこともできます。dots は、最初の 1 体がプランに入り、増やすのはこれからです。会社向けの specialist dots は、別に試している段階です。

自分のパソコンのファイルの開き方も違います。dots は、一度許可すると、取り消すまで開いたままです。Grok Bot は、そのたびに聞いてきます。クラウドの仕事は、どちらもノートパソコンを閉じても止まりません。

使える端末も違います。Grok Bot の概要には、macOS、Windows、Linux、iPhone、iPad、Android と書いてあります。dot を新しく作るのは、パソコンの ChatGPT です。

## 8 月 11 日に、先に書いてあったこと

Grok Bot の公開は 2026-08-11 です。原文は [Introducing Grok Bot](https://x.ai/news/introducing-grok-bot) です。その日の文には、Bot はクラウドのコンピュータを共有する、と書いてあります。複数の Bot が同時に動き、グループの会話で仕事を渡す、ともあります。チャット、Bot、Build が別の道具だという話は <a href="/tips/bot-build-chat-map/">3 つの道具</a> に書いてあります。

同じページに、こうあります。「Over time they become more proactive, picking up work before you need to ask and knowing when something needs your attention.」そのうち、頼まれる前に仕事に取りかかるようになる、という書き方です。読み取りだけ、という制限は、その文にはありません。

その日の料金の文には、Grok Bot の使用量は Grok と Cursor のプランとは別で、Bot に任せた仕事では、その時点のプランの残りは減らない、とあります。2026-10-01 のプラン案内には、週の分を使い切ったあとのオンデマンドは Cursor 経由で、月の支払いの上限の中に入る、と書いてあります。公開日の文と、今の案内は、ここがずれています。いま実際に払うときに当てはまるのは、プラン案内の方です。

## 第三者は Muse と並べた

The Verge は 2026-09-29 に、dots を Meta の Muse と比べています。Muse は無料で、dots は有料のプランから、とその記事は書いています。Muse の中身は、このメモでは確かめていません。このサイトの読者が並べる相手は、Grok Bot です。

ファンが Grok Bot を使い続ける理由は、今すでに Bot を複数動かして、1 台のコンピュータでファイルを渡せることです。繋いだアプリを、読み取りだけで先に調べておいてほしい人には、dots の方が案内が具体的です。どちらが上かは、2026-09-29 の発表だけでは分かりません。

## どうするか

すでに ChatGPT の Pro か、Business の Premium シートを払っていて、繋いだアプリを先に調べてほしい人は、パソコンの ChatGPT を開きます。dot が届いているかを、そこで見ます。Plus、Go、Free、Business の Standard シートは、今回の対象に入っていません。

Bot に名前を付けて、今すぐ複数動かして、ファイルを共有させたいなら、Grok Bot のままでいいです。grok.com の予約と、Bot の Routine は別の機能です。予約の話は <a href="/tips/grok-automations/">時刻で回す仕事</a> に書いてあります。

この発表だけを理由に、どちらかをやめる話にはしません。請求は、別々の会社から来ます。時間のかかる重い仕事の枠の数字は、OpenAI のページに無いので、画面に出るまでここでは書きません。

パスワードは、どちらの会話にも貼りません。
