## 困ること

チャットに長い仕事を頼むと、会話が切れたら続きがありません。ノート PC を閉じたら止まります。毎回、同じ説明から書き直します。

Grok Bot は、そのために出た別のアプリです。クラウドに自分用のコンピュータを持ちます。チャットの前置きを保存するものではありません。チャット、Bot、Build の分け方は <a href="/tips/bot-build-chat-map/">別の道具</a> に書きました。

2026-08-11 の発表から公開され、2026-08-26 に対象のプランが増えました。入れる場所は <a href="https://x.ai/bot" rel="external">x.ai/bot</a> です。サインインは Cursor のアカウントです。grok.com のタブを増やす話ではありません。入口の話は <a href="/tips/three-entrances/">3 か所</a> です。

## 何が違うか

<div class="table-scroll">

| 名前 | 仕事の場所 | 閉じたら |
|---|---|---|
| チャット | grok.com、公式アプリ、X | 会話はそこで終わります |
| **Grok Bot** | クラウドのコンピュータ | 仕事は続きます |
| Grok Build | 自分の PC のターミナル | 自分の PC が止まれば止まります |

</div>

Bot はデスクトップアプリ（macOS、Windows、Linux）と、スマホのアプリから使います。同じ会話が、入っている端末のあいだで続きます。公式は今のところ iPad 向けではない、と書いています。

使用量は、Grok のチャットや Cursor で使える量とは別に数えます。grok.com の Imagine の枚数は増えません（<a href="/tips/free-vs-supergrok/">払う場所は別</a>）。

## コンピュータは 1 台

  <figcaption>同じアカウントの Bot は、コンピュータを 1 台だけ共有します。画面は Bot ごとでも、秘密の境界ではありません。</figcaption>
</figure>

公式のセキュリティ FAQ は、ユーザーごとに Firecracker の仮想マシンが 1 台付く、と書いています。カーネルもメモリも仮想の装置も、そのユーザーだけです。別のユーザーのコンピュータには届きません。ホストは Cursor です。今のところ米国で動きます。自分の会社の中に置くことはできません。自分で作ったイメージを持ち込むこともできません。

同じアカウントの Bot は、**その 1 台を全部で共有します。** ファイルも、ブラウザのログインも、コマンドの認証情報も共有です。ある Bot が保存した続きを、別の Bot が拾えます。Bot を増やしても、パスワードは分かれません。ログインを分けたい仕事は、Cursor のユーザーを分けます。

<div class="table-scroll">

| 部品 | 事実 |
|---|---|
| コンピュータ | ユーザーに 1 台。Firecracker の仮想マシン。米国。Cursor がホスト |
| Bot の画面 | Bot ごとに 1 つ。仕事の場所であって、秘密の境界ではない |
| 画面操作 | 1 つの Bot は、同時に 1 つだけ |
| ファイル | `/workspace` に置く。更新しても、壊れて直しても、残るようにできています |
| プラグイン | アカウント全体。トークンはコンピュータに置かない |
| 目の前の PC | 別物。設定で許可し、その都度承認しないと触らない |

</div>

画面の操作を見るときは、会話から **Agent Computer** を開きます。クリックも入力も、今の状態も見られます。プレビューを閉じても、仕事は続きます。アプリを閉じても、ノートを閉じても、バックグラウンドの仕事と定期の仕事は止まりません。

Bot を消しても、コンピュータ上のファイルとログインは残ることがあります。共有リンクは設定のコピーです。コンピュータもログインも会話の履歴も渡りません。リンクを出す前に、秘密は外してください。

使っていないコンピュータは休眠します。消えるわけではありません。届かなくなったときは Recover です。計画的な更新は Settings → Beta の Update です。Reset は直近の保存に戻すので、保存していない作業は消えることがあります。

コーディングの仕事を、Cursor の Cloud Agent に渡すことがあります。公式は、それは別のコンピュータだ、と書いています。管理者が止められる設定です。

## プラグインと画面操作

API が無いサイトでも、画面を操作して仕事を進めます。公式は、使えるコネクタがあるなら、画面をクリックするよりコネクタを使え、と書いています。コネクタは、いまのアプリでは **Plugins** と出ます。

1. Settings → Plugins を開く
2. 追加する
3. 求められたら、ブラウザでログインする
4. 会話で `@` を付けると、その仕事にコネクタが付きます。`/` は保存した Skill です

入れたコネクタはアカウント全体です。1 つの Bot だけが知っている、にはなりません。

管理者がプラグインを止めても、そのサービスのウェブサイトは止まりません。ウェブサイトまで止めたいなら Network Controls が要ります。公式は Enterprise だけ、と書いています。個人と、自分で契約した Teams には、行き先の許可リストはありません。コンピュータが出て行く IP は、Grok Bot を使っている人で共有している固定の範囲です。会社ごとの専用 IP はありません。一部のサイトは、データセンターの IP だと判断して弾きます。

ログイン、二要素認証、CAPTCHA、支払い、人が入れ、と書いてある画面は、Bot がチャットにパスワードを打つのではなく、人がコンピュータを借りて入れます。パスワードやワンタイムの番号を会話に貼らないでください。対応している接続なら、隠して入れる欄があります。値は会話に残りません。

ブラウザのログインは残るので、毎回入り直す必要はありません。ただしサイト側が切ったり、コンピュータを作り直したりすると、もう一度入ります。

## Skill と Routine

一度うまくいった仕事は、次の 2 つに分けて残します。

<div class="table-scroll">

| 名前 | 何か | いつ使う |
|---|---|---|
| Skill | やり方 | どの Bot からも呼べる。`/` で付ける |
| Routine | いつやるか | 1 つの Bot が持つ。日時か、対応している出来事 |

</div>

Skill には、いつ使うか、必要な入力、手順、確かめ方、返すもの、人に聞くところ、を書きます。Settings → Plugins → Yours で、その Bot に付けるかを選べます。

**Teach a task** が出ているときは、ブラウザの操作を一度見せると、Skill の下書きができます。録れるのは画面の操作だけで、最大 10 分です。マイクの音は録りません。秘密は見せないでください。下書きに、判断のルールと、失敗したときと、人に聞くところを足してから使います。画面に無いときは、終わった仕事から文章で Skill を作ってもらいます。

Routine は、その Bot に「いつやるか」を付けます。ノートを閉じていても動きます。1 つの Bot が持てる Routine は 50 まで。直近の実行記録は 20 件です。消すと元に戻せません。Bot を消すと、その Bot の Routine も消えます。

**Test run** は本番です。サイトを開くし、ファイルも変えるし、コネクタも呼びます。書いてよい入力で試してください。

Slack や GitHub の通知から動かす接続は、Slack や GitHub のプラグインとは別です。広い条件（新しいメッセージ全部）は、使用量を食って、関係ない仕事まで始めます。

長く留守にすると、Routine を止めてよいか聞いてきます。返事が無いと止まります。戻ったら、止まっているものを見てください。

## 人が入れるところ

「何でも勝手に終わらせる」ではありません。送る、買う、消す、公開する、本番の設定を変える、は、Bot の説明に「私に聞いてから」と書いておき、**Require Approval** を足します。

Auto Review は、その手前で、コマンド、プラグイン、画面操作、定期の仕事の書き換え、Cloud Agent への委任を見ます。進めてよい、聞いてから、だめ、のどれかです。記憶への書き込みや、設定の多くは見ません。今は Cursor 側で全員に付いています。自分で切れます。組織でロックするスイッチはありません。

目の前の Mac や Windows は、クラウドのコンピュータとは別です。ローカルのファイルを触らせるには、設定で許可が要ります。公式の初期値は、コマンドごとに聞きます。許可しなければ、仕事はクラウド側だけです。

Grok Bot はクラウドにデータを置く前提です。Cursor の Legacy Privacy Mode では動きません。学習に使わない設定は、Cursor の設定に従います。

日本語で頼むときは、チャットと同じく最初に言語と話題を決めておくと安定します（<a href="/tips/japanese-fix/">会話の最初に 3 行貼る</a>）。

## プランと使用量

2026-09-12 に開いた公式は、対象の書き方が揃っていません。**自分のプランで使えるかは、契約する画面で確かめてください。**

<div class="table-scroll">

| 出典 | 対象 |
|---|---|
| 2026-08-11 の発表 | SuperGrok、Plus、Heavy。Cursor の Pro、Pro+、Ultra。Teams の Standard と Premium |
| 2026-08-26 の発表 | SuperGrok と Cursor Pro と、Teams の全部 |
| 2026-09-12 の料金 | SuperGrok（$30）に Grok Bot access とある |
| 導入ページ | Plus、Heavy。Cursor の Pro+、Ultra。Teams の Standard か Premium |
| Cursor の案内 | 個人の有料 Cursor 全部。個人の SuperGrok、Plus、Heavy。X Premium+。Lite は対象外 |

</div>

Cursor の案内では、個人の SuperGrok や X Premium+ は、Grok Bot の画面から **リンク**します。Cursor のプランが変わるわけではありません。すでに Cursor の有料に入っているときは、リンクしても使用量は足されません。FAQ は、Cursor と SuperGrok の両方があるときは、多いほうを使う、と書いています。足し算ではありません。

使用量は 1 週間ごとです。macOS と iPhone は、同じ Cursor アカウントなら同じ残りです。使い切ったあとは、Cursor 側の On-demand が付いていれば続きます。付いていなければ、リセットまで止まります。無料の試用は日数ではなく、使った分のクレジットです。長い仕事 1 回で尽きることがあります。戻ってきません。

Grok Bot だけが目的で、もう Cursor を使っているなら、Cursor の個人向け Pro のほうが SuperGrok より安くすむことがあります。ただし grok.com で使える量も、API のクレジットも付いてきません（<a href="/tips/free-vs-supergrok/">払う場所は 4 つ</a>）。

## 始め方

1. <a href="https://x.ai/bot" rel="external">x.ai/bot</a> からアプリを入れる
2. Cursor のアカウントでサインインする。会社が SSO なら、いつもの入り方です
3. Bot に、短い名前と、主にやってもらう仕事と、進め方を書く。何でも屋より、仕事を分けた Bot のほうが、あとで覚えている、と公式は書いています
4. 最初の仕事は、成果、見る場所、やってはいけないこと、戻してほしい形、人に聞くタイミング、を書く

公式の例を、日本語の語順に直すとこうなります。コネクタもログインも要らない最初の 1 件です。

```
この PDF を 5 行で要約してください。日付と、決まったことと、まだ決まっていないことを、別の節に分けてください。出典のページを付けてください。元のファイルは書き換えないでください。
```

長い指示は、この形が使いやすいです。プロンプト集はこのサイトには置きません。<a href="https://grokguide.jp" rel="external">grokguide.jp</a> にあります。

```
役割: あなたは○○（例: 日本語の週次メモ係）
扱うこと: ○○だけ
出力の形: ○○
やらないこと: 本番の設定を変えない。英語で答えない。送る前に私に確認する
```

スマホは iPhone（iOS 18 以降）と Android 9 以降です。デスクトップは macOS（Apple silicon と Intel）、Windows（x64 と Arm64）、Linux（x64 と Arm64。`.deb`、`.rpm`、AppImage）。クラウド側のコンピュータは、デスクトップと同じ 1 台です。

## 取り違え

- チャットに Bot 用の長い指示を貼っても、会話が終われば消えます
- ターミナルの grok は、自分の PC でも Bot のコンピュータでも動かせます。画面の中の Build とは別です。Bot の会話で重い仕事をしない書き方は <a href="/tips/bot-uses-build/">重い仕事は grok に渡す</a> です
- Bot をいくつ作っても、ログインは共有です。「この Bot だけがこのパスワードを知っている」にはなりません
- プラグインを止めても、そのサービスのウェブサイトは残ります
- Bot を消しても、コンピュータ上のファイルとログインは残ることがあります
- 共有リンクを開いた人は、あなたのコンピュータには入れません。設定のコピーです
- Cursor のプランと SuperGrok を両方払っても、Grok Bot の使用量は足されません
- Lite では Grok Bot は使えません
- Legacy Privacy Mode のままでは動きません
- 使えるプランの書き方は、ニュースと導入ページと Cursor の案内で揃っていません。画面を見てください
- 会社の中に置くことはできません。専用の出口 IP もありません
