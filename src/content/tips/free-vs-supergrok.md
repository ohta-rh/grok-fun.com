## 先に決めること

クレジットカードの SuperGrok Heavy を解約して、新しいプランで契約し直しました。支払い画面を開いても、Heavy は止まっていませんでした。「レガシー」と「アクティブ」のバッジが出たままでした。

公式の切り替えは、別のやり方です。支払いを終えると、まとめた Cursor と SuperGrok と、有料の X Premium は、自分で止めなくても止まります。切り替えに入れた契約は、使っていない日数の分が自動で戻ります。

自分で先に解約した分の返金は、その日割りとは別です。grok.com で払った SuperGrok は、<a href="https://docs.x.ai/grok/faq" rel="external">FAQ</a> のフォームから返金を申し込みます。通るかどうかは、審査で決まります。

## 移し方

残す人は、何もしません。移る人は、ウェブでやります。今払っている人は、スマホのアプリから始めてもウェブに飛ばされます。まだ払っていない人だけ、アプリの中で契約できます。その支払いは App Store か Google Play です。

|---|---|
| Cursor | <a href="https://cursor.com/unify">cursor.com/unify</a>。Get started |
| Grok | grok.com の設定の請求。または <a href="https://accounts.x.ai/unify">accounts.x.ai/unify</a> |

Cursor を払っている人は、cursor.com/unify で Get started を押します。足すアカウントを選んで、Plus、Premium、Super、Ultra のどれかを選んで、支払いを終えます。Grok から始める人は、設定の請求で Get started を押すか、accounts.x.ai/unify を開きます。X だけを払っていて Cursor の有料が無い人は、x.com の契約設定で足ります。手順は <a href="https://docs.x.ai/x-subscription/unify-accounts" rel="external">How to unify accounts</a> です。

支払いを終えると、まとめた Cursor、SuperGrok、有料の X Premium は止まります。使っていない日数の分は、元の支払いへ別に戻ります。新しい契約の金額からは引きません。新しい請求は、切り替えた日から始まります。

料金のページでは、新しい契約は満額です。発表の FAQ では、変更はすぐに入って、日割りになります。Ultra の支払い画面では、初月だけ 50% オフで、その後は定価でした。

Cursor に前払いが残っている人は、切り替えの請求が満額で出ます。その請求は、前払いから戻ります。残りは、次からの請求に使われます（<a href="https://docs.x.ai/x-subscription/eligibility" rel="external">Unification eligibility</a>）。

一度まとめると、元には戻せません。あとから The X Subscription を止めても、前の Cursor も SuperGrok も X Premium も戻りません。

Ultra の支払い画面を開いているあいだも、SuperGrok Heavy は「レガシー」と「アクティブ」のままでした。次の請求サイクルは 2026-10-17 に始まると出ていました。これは解約の日ではありません。このアカウントは、そのあと Heavy を解約して、新しいプランで契約し直しました。

チームに入っても、今払っている個人の契約は止まりません。切り替えに入れなかったアカウントも、そのまま続きます。どちらも、要らなくなったら自分で止めます。

### 切り替えない人の、使える量

切り替えない人は、2026 年 6 月からの FAQ のままです。使える量は 1 週間ごとに決まっています。1 日ごとの回数ではありません。チャットと Imagine は同じ量から減っていきます（<a href="https://docs.x.ai/grok/faq" rel="external">FAQ</a>）。

- チャットをたくさん使うと、同じ週の Imagine の残りも減ります
- 動画と長いコーディングは、チャットより早く減ります
- 残りは **設定 → Usage** で見られます。使った割合、製品ごとの内訳（FAQ 上は API、Build、Chat、Imagine、Voice）、次にリセットされる日時、追加クレジットの残高が出ます
- 使い切ると、有料の機能はリセットまで止まります。**無料の Chat と Voice は、別の回数で残ります**
- 続けたいときは、追加クレジットを買う、上のプランに変える、Auto Top Up を付ける、のどれかです

「昨日は画像が出たのに今日は出ない」は、たいてい同じ週の残りを別の作業で使ってしまったのが原因です。The X Subscription に移したあとの週の分は、上の「新しい月額」に書きました。

### 追加クレジット

1 週間分を使い切ったあとに、前払いで買い足すものです。

- **Web からしか買えません。** アプリのストア課金では買えません
- **$5 から**買えます
- プランに入っている 1 週間分を使い切ってから減り始めます。使い切るまでは減りません
- 期限は、購入から 1 年です。画面に別の期限があれば、その文面です
- 1 回あたりの単価は、プランに入っている分より高いです
- **Auto Top Up** を付けると、残高が減ったときに決めた額を自動で足します。1 か月の上限も決められます

毎週のように使い切るなら、クレジットを買い続けるより上のプランに変えたほうが安い、と FAQ は案内しています。たまに足りない月の穴埋め、と考えてください。新しい契約で足す分の金額は、請求の画面に出ます。

### 前の契約でよくある取り違え

- 「X Premium なのに grok.com が無料のまま」: 切り替えない限り、別の契約なので、これで正常です
- 「Cursor Pro なのに Imagine の枚数が変わらない」: 2026-10-07 までの Cursor で払っているのは、Grok Bot の分です。切り替えると、1つの週の分から減ります
- 「SuperGrok なのに API が使えない」: 2026-10-07 までは、console.x.ai で別に払います。今の Plus には Grok API が付いています。使った分は、週の分から減らず、API の定価で払います
- 「X Premium なのにターミナルの Build が使えない」: 2026-05-25 の発表では、Premium+ か SuperGrok です
- 「画像の残りが急に減った」: 同じ週の分を、別の作業で使っています
- 「円の値段が公式の USD と合わない」: ストアの値段が正しいです
- 「身に覚えのない高額請求が来た」: 多くは Heavy の年払いです。請求画面でプランと周期を見ます
- 「Web で解約のボタンが開かない」: 広告ブロッカーを外して、シークレットウィンドウで <a href="https://grok.com/?_s=billing" rel="external">grok.com の請求画面</a>を開きます
- 「Heavy は公式に無い」: 2026-09-17 の比較表と Get Heavy にありました。今の料金の先頭に名前はありません
- 「画面の中の Build は Heavy だけ」: 2026-07-28 の発表ではそうでした。2026-08-19 の発表では全プランです。ターミナルの grok とは別です
