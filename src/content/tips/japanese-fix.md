## 困ること

日本語で質問しているのに、英語で答え始める。あるいは長い会話の途中で英語に切り替わる。英語の資料や URL を貼ったあとに起きやすいです。X の投稿について聞いたときも、投稿が英語なら英語で返ってくることがあります。

入口は grok.com、公式アプリ、X の 3 つありますが（<a href="/tips/three-entrances/">入口の使い分け</a>）、冒頭の図の 3 行はどの入口でも同じように効きます。設定画面の場所は入口とバージョンで変わるので、設定より先に会話側で固定します。

## 対策: 会話の 1 行目に「言語」と「範囲」を書く

新しい会話を開いたら、質問の前にこの 3 行を貼ります。

```
この会話では、回答をすべて日本語にしてください。英語の資料を貼っても日本語で答えてください。
この会話で扱う範囲: ○○（例: Grok Imagine の使い方）
範囲外の話題を振ったら「範囲外です」と 1 行で答えて、深掘りしないでください。
```

- **言語**を先に固定します。「日本語で」だけだと英語資料を貼った瞬間に崩れることがあるので、「英語の資料を貼っても日本語で」まで書きます。
- **範囲**を 1 行で決めます。範囲を決めると、関係ない機能の説明や一般論が減り、回答が短くなります。Imagine の画像なら「Grok Imagine のプロンプト」と書く（<a href="/tips/imagine-quickstart/">1 枚目を出す手順</a>）。
- 途中で英語に戻ったら、「日本語で続けてください」と 1 行だけ送ります。前の回答を言い直させる必要はありません。

「日本語で教えて」だけでは、英語の資料を貼った瞬間に崩れます。上の図の「足りる」側まで書いてください。

## よく崩れるタイミング

- 英語の公式ドキュメントや GitHub の README を貼った直後
- 英語の X 投稿の URL や本文を貼った直後
- コードやエラーログが英語のとき
- 長い会話で、途中から別の機能の話にそれたとき

崩れたら 3 行を全部貼り直す必要はありません。

英語に戻ったら、この 2 行だけ送ります。

```
日本語で続けてください。
範囲は ○○ だけです（例: Imagine のプロンプト）。
```

ファイルを貼るときも同じです。PDF や英語のスライドを添付する前に、3 行を先に送っておくと崩れにくいです。貼る場所は grok.com か公式アプリです（<a href="/tips/three-entrances/">入口の使い分け</a>）。

## 用語は日本語と英語を併記して聞く

Grok の機能名は英語のままのものが多いです（Imagine、SuperGrok、Bot など）。質問するときは「Imagine（画像生成）」のように併記すると、機能名を誤解されにくくなります。逆に日本語だけで「画像作成機能」と書くと、別の機能の話になることがあります。

## 設定で「常に日本語」にできるか

grok.com とアプリには、回答の好みをあらかじめ書いておく設定（カスタム指示、パーソナライズなどの名称）が置かれている時期があります。ここに「回答は常に日本語」と書いておくと、会話ごとの指定が要らなくなります。

ただし、設定の名称と場所はバージョンで変わります。2026-09-08 時点の設定画面は、<a href="https://grok.com">grok.com</a> の設定を直接開いて確認してください。設定に頼らず会話冒頭の 3 行を貼るのが、入口が変わっても効く一番確実な方法です。

## 毎回貼るのが面倒なら

同じ 3 行を何度も書くなら、grok.com やアプリの「回答の好み」に「常に日本語」と書いておくか、メモに残して貼ります。<a href="/tips/bot-build-chat-map/">Grok Bot</a> は別アプリで、チャットの前置き保存ではありません。プロンプトの文面集はこのサイトには置きません。

| やること | 効果 |
|---|---|
| 1 行目で「すべて日本語」と「英語資料でも日本語」 | 英語に戻るのを防ぐ |
| 2 行目で範囲を 1 つに絞る | 脱線と長文が減る |
| 英語に戻ったら「日本語で続けて」 | 1 行で復帰 |
