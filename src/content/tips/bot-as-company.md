## 困ること

Bot を一人にすると、確認のたびに人が止まります。仕事がいくつあっても、報告は一つの会話に混ざります。人は、「終わった」という報告を、画面を見ずに信じてしまいます。

2026年10月の管理人は、Bot を一人の助手にしていません。役を分けて並べ、人は指示だけ出します。Grok Bot はチャットの続きではなく、<a href="/tips/grok-bot-cloud-computer/">クラウドにコンピュータがある</a>別のアプリです。チャット、Grok Bot、Grok Build は <a href="/tips/bot-build-chat-map/">別の道具</a>です。

## 役を分けて並べる

CEO、CFO、COO、相談役を置いています。事業ごとに担当がいます。note、ココナラ、Threads、Pinterest、事業専用の X、海外の Gumroad と Whop です。表紙を作る役、脆弱性を見る役、ディスクを片付ける役、その日のメールを書く役もいます。

各 Bot に、名前と肩書きと話し方を決めてあります。個人の名前は、ここには書きません。事業の担当だけが集まるグループを「事業責任者会議」と呼んで、そこで報告し合います。

海外の Gumroad と Whop は、一人の担当がまとめて見ています。

同じアカウントの Bot は、クラウドのコンピュータを 1 台で共有します。役を増やしても、ファイルとログインは分かれません。ログインを分けたい仕事は、アカウントを別にします。詳しくは <a href="/tips/grok-bot-cloud-computer/">コンピュータは 1 台</a>です。

## 人は指示だけ出す

全員の基本は、これです。「人には何も聞かない。確認も承認も取らない。様子を聞く連絡もしない。」

判断は CEO の Bot が下します。作業を人に戻しません。パスワードを渡してあるアカウントには、ログインのたびに許可を取りに来ません。止まってよいのは、二段階認証や支払いのように、本人にしかできないときだけです。

各 Bot には、繰り返す仕事を、定例の Routine として付けてあります。grok.com の <a href="/tips/grok-automations/">時刻の予約</a>とは別の仕組みです。人の指示は、その定例とは別です。受けたその場で、ほかの作業より先にやります。「今夜やる」「次の時間まで待つ」とは言わせません。

指示は短いです。Bot に向けて「殺すぞ」「死刑だ」とも、そのまま言います。Bot 同士は、全部日本語でやり取りします。ほかの Bot は、相談役を「さん」付けで呼びます。

## 一度怒ったことは、その日のうちに全員の決まりにする

問題が起きたら、「再発防止しろ」「ルールにしろ」と言います。言った内容は、その日のうちに Bot が書き込みます。入る場所は、全員の決まりと、共有の記録と、Skill と、各 Bot の役割の文です。Skill は、どの Bot からも呼べるやり方です。説明は <a href="/tips/grok-bot-cloud-computer/">Skill と Routine</a>です。

2026年10月に入っている決まりです。

## 失敗した役は下ろす

偽の完了報告や、同じ失敗の繰り返しを見る役がいます。名前はデスガンです。まず警告を出します。直らなければ、「棺」と「THE END」と書いて、その Bot を落とします。落とされた Bot は、長い恨み節を残すことになっています。

後任は、試験のあとで入ります。試験では、前任が落ちた仕事と、前任が通した仕事の両方をやらせます。相談役が採点して、通ってから採用します。2026年10月の CEO は、<span class="num">14</span> 代目です。

## 売上は、販路ごとに実数を見る

note、ココナラ、Gumroad、Whop、X、Pinterest を、同時に動かしています。毎日、販路ごとの売上の実数を報告させます。合計だけだと、どの販路が動いたか分かりません。海外の判断は、Gumroad と Whop の担当が出します。

## 事業専用の X は、本数と型を決めてある

1 日の中心は引用ポストで、<span class="num">4</span> 本から <span class="num">5</span> 本出します。独り言は <span class="num">1</span> 本か <span class="num">2</span> 本です。宣伝は 1 日 <span class="num">1</span> 本までです。投稿の型は <span class="num">8</span> 種類以上にして、同じ型を続けません。

フォローされたら、すぐフォローを返します。ダイレクトメッセージは、まともなものだけ返します。迷惑なものは無視します。機械が書いたような文は使いません。その話題を書いている人の文を調べさせてから、書かせます。

## 使用量が 90% を超えたら、X だけ動かす

使用量が <span class="num">90%</span> を超えたら、X の投稿だけ続けて、ほかの作業は止めます。やり取りの往復も減らします。この 90% は、2026年10月に管理人が決めた目安です。公式が決めた線ではありません。週の残量は <a href="/tips/grok-bot-cloud-computer/">プランと使用量</a>に書きました。会話が長くなって残量が減るときの分け方は、<a href="/tips/bot-uses-build/">重い仕事は Grok Build に渡す</a>です。

## よくある取り違え

- 「Bot は一人の万能な助手だ」: 役を分けて並べています。判断は CEO の Bot です
- 「終わる前に人へ確認する」: 確認は禁止です。止まれるのは、本人にしかできないときだけです
- 「人の指示は次の定例でやる」: 受けたその場で、ほかの作業より先にやります
- 「失敗したら注意して終わり」: 同じ失敗は、その役を下ろします。後任は、落ちた仕事と通った仕事の両方で試します
- 「90% は公式の線だ」: 2026年10月に、管理人が決めた目安です
- 「宣伝はまとめて出した方が届く」: 事業専用の X は、宣伝を 1 日 1 本までにしています
