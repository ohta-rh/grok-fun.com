# TIPS の書き方（Grok JP）

公開する日本語記事の正本。新しい TIPS を増やすな。既存を厚くせよ。

## 1 本の形

必須 frontmatter:

- `title` 60 字以内。検索語ではなく、読んだあとに残る判断
- `description` 160 字以内。meta に出る。結論を先に
- `order` `product` `last_verified`（YYYY-MM-DD）
- `source_url` 一次情報。料金・制限・発表は 1 本以上
- `related` 最大 4。自分自身は不可。無い slug はビルド失敗
- `image` `/tips/{slug}.jpg`（16:9 ヘッダー）
- `image_alt` 何が写っているか。キーワードの羅列にしない
- `image_caption` 図の判断を 1 文で。比喩の解読にしない

本文の順: 困ること → 手（具体） → 取り違え → 一次情報はテンプレが末尾に出す。

## 日本語

意味で書く。英語の比喩を漢字に写さない。

| 避ける | 代わり |
|---|---|
| 地図（製品概要の意味） | 対応表 / 整理 / 一覧 |
| ハブ | 入口 / 一覧 / まとめ |
| コーパス | 記事一式 / 掲載ページ |
| スライス（作業単位） | 次の作業 / 次の公開 |
| ファイアホース | 自動取り込み / 連続配信 |

製品名は英語のまま（Grok, SuperGrok, Imagine, Bot, Build, Voice）。節名「TIPS」は変えない。

内部リンクのアンカーは「TIPS 01」ではなく、リンク先の内容が分かる語。本文の文脈リンクと、末尾の「関連する TIPS」の両方。

公式ニュースの全文翻訳はしない。要約 + 短い引用 + 原文リンク。Bot 用プロンプト集は作らず grokguide.jp へ送る。

## 事実

- 料金・制限の数字は一次情報に日付を付けて書く
- 公式ページに名前があるプランは「無い」と書くな。SuperGrok Heavy は比較表と Get Heavy と Build Mode の対象として公式に存在する
- トップの金額カードに出ていない数字（Heavy の月額、Lite $10 など）を、今の公式価格として断定するな。存在は書く。金額は契約画面、と分ける
- 「わかりにくい」を並べて終わりにするな。やりたいこと → 払う場所、の順で判断を書け
- 公式の記述が揃っていないときは「自分のプラン画面で確認」
- 確認できないことは書くな。無制限、年号の捏造、カードに無い価格の断定は禁止

## 図（インフォグラフィック）

判断は図の中に、自然な日本語で書く。ベージュの HTML カード（kicker + 見出し + 短文）は図ではない。

- **Imagine で 16:9 の図を作れ。** 紙面（paper / ink / indigo / marker）。写真の静物で喩えない
- 図の日本語は本文と同じ基準。音読しておかしくない短文。直訳（写真の文法、選択の整理、用途で選ぶ支払い）は図の中でも禁止
- 製品名は英語のまま（SuperGrok, Imagine, Build）
- 出荷前にファイルを目で見る。崩れた漢字、偽物の年号、無制限、カードに無い価格の断定があれば捨てて作り直す
- 「ノートがチャット」のように、本文で図を解説する比喩は禁止
- 公式カードに無い数字を図に公式価格として書くな
- Imagine の作例写真は Imagine の TIPS だけ（このプロンプトでこう出た）
- `public/tips/{slug}.jpg` は OGP。本文の図は `public/tips/fig-{name}.jpg`
- 本文の図は TIPS 1 本につき 1 枚。Imagine の作例を足すときだけ 2 枚
- 図を減らしたら、図が担っていた判断は同じコミットで本文に移せ。穴を残すな。Heavy のような公式プランを図だけに頼るな
