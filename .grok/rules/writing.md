# TIPS の書き方（Grok JP）

公開する日本語記事の正本。新しい TIPS を増やすな。既存を厚くせよ。

## 1 本の形

必須 frontmatter:

- `title` 60 字以内。検索語ではなく、読んだあとに残る判断
- `description` 160 字以内。meta に出る。結論を先に
- `order` `product` `last_verified`（YYYY-MM-DD）
- `source_url` 一次情報。料金・制限・発表は 1 本以上
- `related` 最大 4。自分自身は不可。無い slug はビルド失敗
- `image` `/tips/{slug}.jpg`（16:9 ヘッダー）
- `image_alt` 何が写っているか。キーワードの羅列にしない
- `image_caption` 比喩の説明。画像に文字を頼らない

本文の順: 困ること → 手（具体） → 取り違え → 一次情報はテンプレが末尾に出す。

## 日本語

意味で書く。英語の比喩を漢字に写さない。

| 避ける | 代わり |
|---|---|
| 地図（製品概要の意味） | 対応表 / 整理 / 一覧 |
| ハブ | 入口 / 一覧 / まとめ |
| コーパス | 記事一式 / 掲載ページ |
| スライス（作業単位） | 次の作業 / 次の公開 |
| ファイアホース | 自動取り込み / 連続配信 |

製品名は英語のまま（Grok, SuperGrok, Imagine, Bot, Build, Voice）。節名「TIPS」は変えない。

内部リンクのアンカーは「TIPS 01」ではなく、リンク先の内容が分かる語。本文の文脈リンクと、末尾の「関連する TIPS」の両方。

公式ニュースの全文翻訳はしない。要約 + 短い引用 + 原文リンク。Bot 用プロンプト集は作らず grokguide.jp へ送る。

## 事実

- 料金・制限の数字は一次情報に日付を付けて書く
- 公式カードに無い数字（Lite $10、Heavy $300 など）を公式価格として扱わない
- 公式の記述が揃っていないときは「自分のプラン画面で確認」
- 確認できないことは書かず、「公式を確認してください」と書く

## 図（インフォグラフィック）

差し込む図は賑やかしではない。そのページの判断が 10 秒で読める図にする。

- **文字・数字・構造が正確である図は HTML**（`Infographic.astro` か本文の `<figure class="infofig">`）。Imagine にラベルや料金を描かせない
- 紙面トークン（paper / ink / indigo / marker）。影とヒーローは使わない
- 公式カードに無い数字を図に書かない。日付付きの一次情報だけ
- レイアウト: 既定は 1 列。4 項目は最大 2×2。本文の measure は 40rem なので 4 列は使うな
- `public/tips/{slug}.jpg` は OGP 兼ヘッダー（全 TIPS）。読める文字・数字・ロゴ・実在の人物を描かない
- 本文の追加写真は別名（例: `usage-pool.jpg`）。比喩だけ。意味は figcaption に書く。事実を写真に載せない
- Imagine の作例写真は Imagine の TIPS だけ（「このプロンプトでこう出た」の証拠）。出荷前にファイルを目で見る
